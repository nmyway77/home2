비교급
1. 쓰임: 둘 이상을 비교하여 말할 때
2. 짧은 단어: 형용사/부사 원급 + er + than + 비교대상
I'm tall. → I'm taller than you.
나는 키가 커. → 나는 너보다 키가 더 커.
I can run fast. → I can run faster than him.
나는 빨리 달릴 수 있어. → 나는 그보다 더 빨리 달릴 수 있어.
3. 긴 단어: more 형용사/부사 원급 + than + 비교대상
This sofa is more comfortable than the other one.
이 소파가 다른 소파보다 더 편해.
My dad drives more carefully than my brother.
나의 아빠는 나의 오빠보다 더 조심스럽게 운전해.
4. 짧은 단어 = 1음절, 2음절 중 (y)로 끝나는 단어 : thick → thicker · happy → happier / 긴 단어 = 2음절 이상 : difficult → more difficult
5. 비교급 강조: very를 쓰지 않고 much, still, even, far, a lot(훨씬)
Today is much hotter than yesterday.

최상급

1) '어떤 사람이나 대상이 있다' → 「~가/이 있다」
2) ① There is + (단수)명사 → There is a computer on the desk. (책상 위에 컴퓨터가 있다.) ② There are + (복수)명사 → There are pictures on the wall. (벽에 사진들이 있다.)
