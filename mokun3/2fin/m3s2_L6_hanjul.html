[본문 1] 아들과 아빠의 대화 — 주말 캠핑 고민 (텐트 · 강아지)

1
Son: What should we do this weekend, Dad? / Dad: Why don't we go camping?
▶ 아들: 아빠, 우리 이번 주말에 뭐 할까요? / 아빠: 우리 캠핑 가는 게 어떨까?
📌 weekend 주말 / go camping 캠핑하러 가다
✏️ Why don't we + 동사원형 ~? = 제안 (= Let's ~ / How about -ing ~?) / go -ing = ~하러 가다
문장 분석 보기
✂️ 끊어 읽기

What [O: 의문사] / should [조동사] / we [S] / do [V] / this weekend [시간 부사구], / Dad [호칭]?
무엇을 / ~해야 할까 / 우리가 / 하다 / 이번 주말에 / 아빠

Why don't we [제안 표현] / go camping [V + 동명사]?
우리 ~하는 게 어때 / 캠핑하러 가다

📘 핵심 문법
  • 의문사 + should + 주어 + 동사원형? : "~해야 할까?, ~할까?" 하고 상대의 의견을 묻는 표현. should 뒤는 반드시 동사원형(do).
  • Why don't we + 동사원형 ~? : "우리 ~하는 게 어때?" (제안). 이유를 묻는 질문이 아님.
    = Let's go camping. = How about going camping? = What about going camping? = Shall we go camping?
  • How about / What about 뒤에는 동명사(going), Why don't we / Let's 뒤에는 동사원형(go) — 바꿔 쓰기 시 형태 주의.
  • go + -ing : ~하러 가다 → go camping, go fishing, go shopping, go swimming.
  • 유사 예문: Why don't we eat out tonight? 오늘 밤에 외식하는 게 어때?
🔑 주요 단어
  • weekend (명) 주말 ↔ weekday 평일
  • camp (동) 야영하다 / (명) 캠프 → camping (명) 캠핑, camper (명) 야영객
👉 대명사 지칭

we = 아들과 아빠(가족)

⚠️ 출제 포인트: 제안 표현 바꿔 쓰기(Why don't we go ~ = How about going ~), go camping의 -ing 형태, 대화의 시작 = 글 전체의 계기(주말 캠핑 계획).
2
Son: But we don't have a tent. Should we buy one? Also, who will take care of our dog?
▶ 아들: 그런데 우리는 텐트가 없잖아요. 하나(= a tent) 사야 할까요? 또 우리 강아지는 누가 돌봐요?
📌 also 또한 ≒ besides, in addition / take care of ~을 돌보다 ≒ look after, care for
✏️ one = 같은 종류의 불특정한 하나 (it ✕ → it은 바로 그 물건) / who = 의문사가 주어 → who + (조)동사 어순
문장 분석 보기
✂️ 끊어 읽기

But / we [S] / don't have [V] / a tent [O]. → 3형식

Should [조동사] / we [S] / buy [V] / one [O]? → 우리가 (텐트) 하나를 사야 할까?

Also, / who [S: 의문사] / will take care of [V] / our dog [O]? → 또한 누가 우리 강아지를 돌볼까?

📘 핵심 문법
  • 부정대명사 one : 앞에 나온 명사와 같은 종류의 불특정한 것 하나 (a + 명사). 텐트가 없으니 '아무 텐트나 하나' → one.
    it은 앞에 나온 바로 그 물건(the + 명사)을 가리키므로 여기서는 쓸 수 없다.
    예: I lost my pen. I need to buy one. (새 펜 하나) / I lost my pen, but I found it. (잃어버린 그 펜)
  • 의문사가 주어인 의문문 : who가 주어 → 의문사 + (조)동사 + ~? 어순. do/does를 넣지 않는다. → Who does will take care…(X)
  • Should we ~? : 조동사 should를 이용해 상대의 생각을 묻는 의문문.
🔑 주요 단어
  • tent (명) 텐트, 천막
  • also (부) 또한 ≒ besides, in addition, moreover
  • take care of ~을 돌보다 ≒ look after, care for → care (명) 돌봄 / careful (형) 조심하는
👉 대명사 지칭

one = a tent (불특정한 텐트 하나) / we·our = 아들과 아빠(가족)

⚠️ 출제 포인트: one ↔ it 어법(빈출), take care of = look after 동의어, 아들의 걱정 2가지(① 텐트 없음 ② 강아지 돌볼 사람 없음) → 뒤에 나오는 앱 2개와 연결되는 내용일치 문제.

▶ 아빠: 걱정하지 마. 내가 우리를 도와줄 수 있는 몇 가지 앱들을 알고 있지.
📌 app 앱, 응용 프로그램 (= application)
✏️ that = 주격 관계대명사, 선행사 some apps (= which)

✂️ 끊어 읽기

Don't worry. [부정 명령문] 걱정하지 마.

I [S] / know [V] / some apps [O: 선행사] / [that (S') can help (V') us (O')] [주격 관계대명사절].
나는 / 안다 / 몇몇 앱들을 / [우리를 도와줄 수 있는]

📘 핵심 문법
  • 주격 관계대명사 that : 선행사 some apps(사물)가 관계절에서 주어 역할 → that / which 가능, 생략 불가. 뒤에 동사(can help)가 바로 온다.
  • 선행사가 사람이면 who/that, 사물·동물이면 which/that.
  • 부정 명령문 : Don't + 동사원형 (~하지 마라).
  • 유사 예문: I have a friend that can speak French. 나는 프랑스어를 할 수 있는 친구가 있다.
🔑 주요 단어
  • worry (동) 걱정하다 / (명) 걱정 → worried (형) 걱정하는
  • app (명) 앱 = application (응용 프로그램)
👉 대명사 지칭

that = some apps / us = 아들과 아빠(가족)

⚠️ 출제 포인트: 주격 관계대명사 that/which 선택·생략 불가, 이 문장을 계기로 두 앱(Ask Your Neighbors, Pet Sitter Finder)이 소개된다는 글의 흐름(문장 삽입·순서 문제).

4
Borrow from your neighbors!
▶ 당신의 이웃들로부터 빌려라!
📌 borrow 빌리다 ↔ lend 빌려주다 / neighbor 이웃
문장 분석 보기
✂️ 끊어 읽기

Borrow [V: 명령문] / from your neighbors [전치사구]!
빌려라 / 당신의 이웃들로부터 → 앱 소개 광고 문구(슬로건)

📘 핵심 문법
  • 명령문 : 주어(you) 없이 동사원형으로 시작 → 광고·안내 문구에서 자주 쓰인다.
  • borrow A from B : B에게서 A를 빌리다 / lend A to B = lend B A : B에게 A를 빌려주다.
  • 유사 예문: Can I borrow your pen? (내가 빌림) / Can you lend me your pen? (네가 빌려줌)
🔑 주요 단어
  • borrow (동) 빌리다 → borrower (명) 빌리는 사람 ↔ lend(빌려주다) – lender(빌려주는 사람)
  • neighbor (명) 이웃 → neighborhood (명) 동네, 이웃
👉 대명사 지칭

your = 앱 사용자(독자)의

⚠️ 출제 포인트: borrow ↔ lend 혼동(빈출 어휘), borrow 뒤 전치사 from. 뒤에 나오는 lender(빌려주는 사람)와 연결.
5
Ask Your Neighbors helps people easily find items that they can borrow from others.
▶ Ask Your Neighbors는 사람들이 다른 사람들로부터 빌릴 수 있는 물건을 쉽게 찾도록 돕는다.
📌 easily 쉽게 / item 물건, 물품 ≒ thing, product
✏️ 앱 이름은 단수 취급 → helps / help + 목적어 + (to) 동사원형 / that = 목적격 관계대명사(생략 가능), 선행사 items
문장 분석 보기
✂️ 끊어 읽기

Ask Your Neighbors [S: 앱 이름] / helps [V] / people [O] / easily find [OC] / items [find의 목적어: 선행사] / [that they (S') can borrow (V') from others] [목적격 관계대명사절].

Ask Your Neighbors는 / 돕는다 / 사람들이 / 쉽게 찾도록 / 물건들을 / [그들이 다른 사람들로부터 빌릴 수 있는] → 5형식

📘 핵심 문법
  • 고유명사(앱 이름) = 단수 취급 : Neighbors가 복수형처럼 보여도 하나의 앱 이름 → helps (help ✕).
  • help + 목적어 + (to) 동사원형 : 목적격보어로 동사원형 또는 to부정사 둘 다 가능 → help people (to) find. finding ✕.
  • 목적격 관계대명사 that : 선행사 items가 borrow의 목적어 역할 → 관계절이 불완전(borrow 뒤 목적어 없음). which로 바꿀 수 있고 생략 가능.
  • 부사 easily가 동사원형 find를 꾸민다.
  • 유사 예문: My sister helped me (to) clean my room. 언니는 내가 방 청소하는 것을 도와주었다.
🔑 주요 단어
  • easily (부) 쉽게 ← easy (형) 쉬운
  • item (명) 물건, 물품 ≒ thing, product
  • others (대) 다른 사람들
👉 대명사 지칭

that = items / they = people (앱 사용자들)

⚠️ 출제 포인트: helps 수일치(앱 이름 단수), help + O + (to) V 형태, 목적격 관계대명사 생략 가능 여부, 배열영작(helps people easily find items that ~).

First, users download the app and search for another user that has the item they need.
▶ 우선, 사용자들은 그 앱을 내려받고 자신이 필요로 하는 물건을 가지고 있는 또 다른 사용자를 찾는다.
📌 download 내려받다 / search for ~을 찾다 ≒ look for
✏️ download ~ and search ~ 병렬 / that = 주격 관계대명사, 선행사 another user(단수) → has / the item (that) they need = 목적격 관계대명사 생략
문장 분석 보기
✂️ 끊어 읽기

First, / users [S] / download [V1] the app [O1] / and search for [V2] / another user [O2: 선행사] / [that (S') has (V') the item (O') / ((that) they need)] [관계대명사절 안의 관계대명사절].

우선 / 사용자들은 / 앱을 내려받는다 / 그리고 찾는다 / 또 다른 사용자를 / [물건을 가진 / (그들이 필요한)]

📘 핵심 문법
  • 병렬 구조 : 주어 users에 동사 download와 search for가 and로 연결(둘 다 현재형 복수).
  • 주격 관계대명사 that + 수일치 : 선행사 another user가 단수 → 관계절 동사도 단수 has (have ✕). 관계절 동사는 선행사에 수일치!
  • 목적격 관계대명사 생략 : the item (that) they need — need의 목적어 역할이므로 생략됨. 명사 + 주어 + 동사가 바로 이어지면 목적격 관계대명사 생략을 의심하라.
  • another + 단수명사 : another user (another users ✕). cf. other + 복수명사(other users).
  • 유사 예문: I'm looking for a person that has the book (that) I want.
🔑 주요 단어
  • first (부) 우선, 첫째로 → 다음 문장 Then과 짝을 이루는 순서 연결어
  • user (명) 사용자 ← use (동) 사용하다
  • download (동) 내려받다 ↔ upload 올리다
  • search for ~을 찾다 ≒ look for
👉 대명사 지칭

that = another user / they = users (앱을 내려받은 사용자들)

⚠️ 출제 포인트: 관계절 동사 수일치 has ↔ have(빈출 어법), 목적격 관계대명사 생략 위치 찾기, another + 단수명사, 앱 이용 순서(내려받기 → 찾기 → 가져오기 → 반납) 순서 배열 문제.

문장 분석 보기
✂️ 끊어 읽기

Then / they [S] / pick up [V1] the item [O1] / and return [V2] it [O2] / later [부사].

📘 핵심 문법
  • 순서 연결어 : First(우선) → Then(그런 다음) → Finally(마지막으로). 절차 설명문에서 순서 배열 문제의 단서.
  • 병렬 : pick up ~ and return ~ (주어 they 공유, 현재형).
  • 이어동사 pick up + 대명사 : 목적어가 대명사면 반드시 가운데 → pick it up (pick up it ✕). 명사는 둘 다 가능(pick up the item = pick the item up).

🔑 주요 단어
  • pick up ~을 찾아오다, 가져오다 / (차로) 데리러 가다
  • return (동) 반납하다, 돌려주다 ≒ give back / 돌아오다 ≒ come back / (명) 반납, 귀환
  • later (부) 나중에
👉 대명사 지칭

they = users (앱 사용자들) / it = the item (빌린 물건)

⚠️ 출제 포인트: First → Then 순서(문장 순서 배열), pick it up 어순, it이 가리키는 대상 쓰기, return = give back.

문장 분석 보기
✂️ 끊어 읽기

I [S] / asked for [V1] a board game [O1] / and got [V2] one [O2] / in less than 30 minutes [시간 부사구].
나는 / 보드게임을 요청했다 / 그리고 하나를 얻었다 / 30분도 안 되어

one = a board game

⚠️ 출제 포인트: one ↔ it, 30분도 안 되어 구했다 → '빠르고 쉽게 빌릴 수 있다'는 장점(내용일치: "30분 이상 걸렸다" ✕).
9
I love saving money by borrowing things that I don't often need.
