UNIT 31조동사 관용표현

핵심 원리

조동사가 들어간 관용표현은 뒤에 오는 동사 형태(동사원형 / ~ing / to-v)와 짝이 되는 접속사(than / as)가 정해져 있다. 형태를 통째로 외워야 하며, 시험은 그 형태를 바꿔 놓고 묻는다.

would rather stay naked than wear furs (would rather A than B: A·B 모두 동사원형)
cannot help living (= cannot but live = cannot help but live) / I cannot stress too much (아무리 ~해도 지나치지 않다)

조동사 관용표현 (암기표)

표현뜻뒤 형태예

자주 틀리는 형태

  • would rather to stay ×, would rather stay than wearing ×
  • may as well A than B × → as B
  • cannot help to live ×, cannot but expressing ×
  • cannot help but remember … and to be depressed → and be (원형 병렬)
  • need(조동사)는 부정·의문문에서만: need not go / Need I go? — 긍정문에서는 need to-v

같은 지문의 다른 포인트

  • make you do your schoolwork, set your schedule, or get to class — make + O + 원형 병렬
  • has not been damaged — 현재완료 수동 / An old man holding a puppy — 현재분사 수식

시험 포인트

  • would rather / had better / may as well / cannot but 뒤 → 동사원형.
  • would like / ought 뒤 → to-v; cannot help 뒤 → ~ing.
  • than ↔ as 짝: would rather ~ than, may as well ~ as.

UNIT 32used to / be used to

핵심 원리

used가 들어간 세 표현은 형태가 비슷하지만 전혀 다르다. used to + 동사원형(~하곤 했다, 과거의 습관·상태), be used to + ~ing/명사(~에 익숙하다), be used to + 동사원형(~하는 데 사용되다 — use의 수동태). 뒤에 오는 동사 형태와 주어의 의미로 구별한다.

They became used to being slaves. (노예인 것에 익숙해졌다 — 익숙함 → ~ing)
culture is used to survive the natural world (문화가 살아남는 데 사용된다 — 수동 → 동사원형)
There used to be many tigers. (예전에 있었다 — 과거 습관·상태)

세 가지 used 구별표

표현뜻뒤 형태판별예
used to + 동사원형~하곤 했다, 예전엔 ~였다 (지금은 아님)동사원형앞에 be동사 없음; 과거의 습관·상태I used to play tennis. / There used to be a church here.
be used to + ~ing / 명사~하는 데(에) 익숙하다동명사·명사주어가 사람·생물, "익숙하다"로 해석 (= be accustomed to)became used to being slaves / people are used to living with discomfort
be used to + 동사원형~하기 위해 사용되다동사원형 (목적의 to부정사)주어가 사물·도구, "사용되다"로 해석 (use의 수동태)The arts are used to commemorate events. / culture is used to survive

판단 절차

  1. used 앞에 be동사가 있는가? 없으면 → used to + 원형(과거 습관).
  2. be동사가 있으면 주어를 본다: 주어가 "익숙한" 존재(사람)면 → ~ing; 주어가 "사용되는" 물건·수단이면 → 동사원형.
  3. 해석으로 확인: "익숙하다" vs "사용되다".
  • people are not used to live with discomfort → living (사람이 익숙하지 않음)
  • They are used to commemorating events → commemorate (예술이 기념하는 데 사용됨)

관련 표현

  • get / become used to ~ing: ~에 익숙해지다 (상태 변화)
  • be accustomed to ~ing = be used to ~ing
  • would + 동사원형: ~하곤 했다 (과거의 반복 동작만; 상태 ×) — There would be a church ×

같은 지문의 다른 포인트

  • would rather bear ~ than flee (UNIT 31) / insisted that they had been happy — 사실 주장 → 시제 일치(당위 아님, UNIT 29)
  • the way your buddy does — 대동사 / culture does help — 강조의 do

시험 포인트

  • be used to 뒤: 사람 주어·익숙 → ~ing / 사물 주어·사용 → 원형.
  • used to + 원형은 be동사 없음; 과거 상태(There used to be) 가능.
  • get used to ~ing (to-v ×).

핵심 원리

가정법은 사실과 반대를 가정한다. 가정법 과거(현재 사실의 반대): If + S + 과거동사, S + would/could + 동사원형. 가정법 과거완료(과거 사실의 반대): If + S + had p.p., S + would/could + have p.p. 조동사 + have p.p.는 과거 사실에 대한 추측·가정에도 쓰인다.

핵심 원리

전치사 뒤의 동사는 반드시 동명사(~ing)다. 전치사 뒤에 to부정사·동사원형은 올 수 없다. 동명사의 부정은 not + ~ing, 의미상 주어는 소유격/목적격, 완료형은 having p.p.이다.

동명사의 부정·의미상 주어·완료

  • 부정: not / never + ~ing — for not showing gratitude / blamed for not being on time
  • 의미상 주어: 소유격(목적격) + ~ing — this resulted in her feelings being hurt (feelings가 상처받음; were는 전치사 뒤 동사 불가)

  • 수동 동명사: being p.p. — her feelings being hurt

전치사 to + ~ing (UNIT 37 예고)

  • look forward to ~ing, be used to ~ing, object to ~ing, when it comes to ~ing — 여기의 to는 전치사

동명사는 동사의 성질을 유지해 목적어·부사를 취할 수 있고, 명사는 목적어를 바로 취하지 못하며(of 필요) 형용사의 수식을 받는다. 뒤에 목적어가 있으면 동명사, 관사·형용사가 앞에 있으면 명사를 고른다.

명사 + to부정사 / 관용 구문

  • the time had come to start his own business — time + to-v (형용사적)
  • invited him to buy — invite + O + to-v (5형식)
  • focused on making his restaurant efficient — 전치사 on + ~ing
  • went from catching footballs to flipping hamburgers — from ~ing to ~ing
  • goes from being an abused boy to being a star — 전치사 to + 동명사(UNIT 37)

같은 지문의 다른 포인트

  • not once does he blame ~ — 부정어구 문두 도치
  • the raise he had requested was turned down — 과거완료(요청이 먼저)
  • Frustrated as he was — 양보(= Though he was frustrated)

시험 포인트

  • refuse / manage / decide / want / hope / fail + ~ing → ×.
  • would like to-v (would like ~ing ×).
