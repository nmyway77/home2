01
One of the things that makes uncertainty difficult for members of the public to appreciate is that the significance of uncertainty is relative.
🔊
대중의 구성원들이 불확실성을 제대로 이해하기 어렵게 만드는 것들 중 하나는, 불확실성의 중요성이 상대적이라는 것이다.
📌uncertainty불확실성appreciate제대로 이해하다members of the public일반 대중significance중요성relative상대적인certain ↔ uncertain → uncertainty확실한 ↔ 불확실한 → 불확실성 [반의·파생]significant → significance중요한(형) → 중요성(명) [파생]
📐 문장 구조도
✏️ 문법One of the + 복수명사 + 단수동사: One of the things ~ is that ~ — 문장 전체의 주어는 One(단수) → 동사 is. / make + O + 형용사 (5형식): makes uncertainty difficult ~ to appreciate = 불확실성을 이해하기 어렵게 만들다 — difficult가 목적보어. / 의미상 주어 for + 명사: difficult for members of the public to appreciate = '대중이' 이해하기에 어려운 — to appreciate의 행위 주체. / 보어절 that: is that the significance ~ is relative — that절이 주격보어(~라는 것이다).
【주제 — 불확실성의 중요성은 '상대적'이다】 글 전체의 핵심 문장. 대중이 불확실성을 이해하기 어려운 이유는 그 중요성(significance)이 절대적이지 않고 상대적(relative)이기 때문. ★ S02부터 지구-태양 거리라는 구체적 예시로 이를 증명한다.
ⓑ
02
Take, for example, the distance between Earth and the sun: 1.49597 x 10⁸ km, as measured at one point during the year.
🔊
예를 들어, 지구와 태양 사이의 거리, 즉 연중 어느 한 시점에 측정된 대로의 1.49597 x 10⁸ km를 보자.
📌take ~ for example~을 예로 들다distance거리measure측정하다at one point어느 한 시점에measure → measurement측정하다(동) → 측정(명) [파생]distant → distance먼(형) → 거리(명) [파생]
📐 문장 구조도
✏️ 문법Take, for example, ~ (명령문): Take, for example, the distance ~ = ~을 예로 들어 보라 — 주어 없는 명령문, for example이 콤마 삽입. / 콜론(:) 동격: the distance ~ : 1.49597 x 10⁸ km — 콜론 뒤 수치가 거리의 구체적 값(동격). / as + 과거분사: as measured at one point ~ = 측정된 대로 — 거리가 '측정되는' 수동 관계 → 과거분사.
【예시 도입 — 지구-태양 거리 수치】 주제를 증명할 예시: 연중 한 시점에 측정된 지구-태양 거리 1.49597 x 10⁸ km. ★ S03~S04가 이 수치가 정밀한지 아닌지를 양쪽에서 따진다.
03
This seems relatively precise; after all, using six significant digits means I know the distance to an accuracy of one part in a million or so.
🔊
이것(= 인용된 거리 수치)은 비교적 정밀해 보이는데, 어쨌든 여섯 개의 유효 숫자를 사용한다는 것은 내가 그 거리를 약 100만분의 1 정도의 정확도로 알고 있다는 것을 의미하기 때문이다.
📌relatively비교적precise정밀한after all어쨌든, 따지고 보면significant digit유효 숫자accuracy정확도or so~쯤, ~ 정도precise → precision정밀한(형) → 정밀도(명) [파생]accurate → accuracy정확한(형) → 정확도(명) [파생]
📐 문장 구조도
✏️ 문법동명사 주어 + 단수동사: using six significant digits means ~ — 동명사구 주어는 단수 취급 → means. / seem + 형용사 (2형식): This seems relatively precise = 정밀해 보인다 — seem 뒤 형용사 보어. / 접속사 that 생략: means (that) I know ~ — means의 목적어절에서 that 생략.
【한쪽 판단 — '정밀해 보인다' (유효 숫자 6개)】 유효 숫자 6개 = 100만분의 1 수준의 정확도 — 이 기준으로 보면 이 수치는 충분히 정밀(precise)하다. ★ S04의 However가 정반대 판단을 내놓는다.
04
However, if the next digit is uncertain, that means the uncertainty in knowing the precise Earth-sun distance is larger than the distance between New York and Chicago!
🔊
그러나 만약 그다음 자리 숫자가 불확실하다면, 그것(= 다음 자리 숫자가 불확실하다는 것)은 정확한 지구-태양 거리를 아는 데 있어서의 불확실성이 뉴욕과 시카고 사이의 거리보다 더 크다는 것을 의미한다!
📌digit자리 숫자uncertain불확실한in V-ing~하는 데 있어서larger than~보다 더 큰precise ≒ exact, accurate정밀한, 정확한 [유의]know / knew / known알다 [불규칙 3단]
📐 문장 구조도
✏️ 문법조건 부사절 if: if the next digit is uncertain, that means ~ — 조건절 + 주절. / that = 앞 절 내용 지칭: that means의 that = '다음 자리 숫자가 불확실하다는 것'(if절 내용). / 전치사 in + 동명사: the uncertainty in knowing ~ = ~을 아는 데 있어서의 불확실성 — in 뒤 동명사. / 비교급 larger than: is larger than the distance ~ = ~의 거리보다 더 크다.
【반전 — 그 오차는 뉴욕-시카고 거리보다 크다!】 같은 수치라도 일곱째 자리가 불확실하면 오차가 뉴욕-시카고 간 거리를 넘는다 — 관점을 바꾸면 전혀 정밀하지 않다. ★ S03과 S04의 대비가 '상대적'이라는 주제(S01)를 증명.

05
Whether or not the quoted number is “precise” therefore depends on what I'm intending to do with it.
🔊
인용된 수가 '정밀한지' 아닌지는 따라서 내가 그것(= 인용된 수)을 가지고 무엇을 하려고 하는지에 달려 있다.
📌whether or not~인지 아닌지quote인용하다therefore따라서depend on~에 달려 있다intend to V~할 작정이다depend on ≒ rely on~에 달려 있다, 의존하다 [유의]intend → intention의도하다(동) → 의도(명) [파생]
📐 문장 구조도
✏️ 문법whether or not 명사절 주어: Whether or not the quoted number is “precise” — whether절이 문장의 주어(단수 취급 → depends). / depend on + 의문사절 what: depends on what I'm intending to do with it — what절이 전치사 on의 목적어(do의 목적어 자리가 비어 what). / 과거분사 수식 quoted: the quoted number = 인용된 수 — 수가 '인용되는' 수동 → 과거분사.
【결론 — 정밀함은 '무엇에 쓰려는가'에 달렸다 (빈칸 핵심)】 정밀함의 판단 기준은 수치 자체가 아니라 사용 목적(what I'm intending to do with it)이다. ★ S06~S07이 두 가지 목적으로 이를 예증하며 글을 닫는다.
06
If I care only about what minute the sun will rise tomorrow, then the number quoted here is fine.
🔊
만약 내가 내일 태양이 몇 분에 뜰지에만 관심이 있다면, 그렇다면 여기에 인용된 수는 괜찮다.
📌care about~에 관심을 두다what minute몇 분에rise뜨다, 떠오르다fine괜찮은, 충분한rise / rose / risen뜨다, 오르다(자동사) [불규칙 3단]rise ↔ raise(스스로) 오르다 ↔ ~을 올리다(타동사) [혼동 페어]
📐 문장 구조도
✏️ 문법전치사 about + 의문사절: care only about what minute the sun will rise ~ — 「what minute(의문사)+S+V」 절이 about의 목적어. / 과거분사 후치수식 quoted: the number quoted here = 여기에 인용된 수 — quoted가 number를 뒤에서 수식. / if ~, then ~ (조건-결과): If I care ~, then the number ~ is fine — 조건절과 주절을 then이 명시적으로 연결.
【예증 1 — 일출 시각용이라면 이 수치로 충분】 목적이 내일 일출이 몇 분인지 정도라면, 지금의 수치는 충분히 정밀하다. ★ S07의 반대 사례와 짝을 이룬다.
07
If I want to send a satellite to orbit just above the sun, however, then I would need to know distances more accurately.
🔊
그러나 만약 내가 태양 바로 위를 공전하도록 위성을 보내고 싶다면, 그렇다면 나는 거리를 더 정확하게 알아야 할 것이다.
📌satellite위성orbit공전하다, 궤도를 돌다just above~ 바로 위accurately정확하게would need to V~해야 할 것이다accurate → accurately정확한(형) → 정확하게(부) [파생]send / sent / sent보내다 [불규칙 3단]
📐 문장 구조도
✏️ 문법목적의 to부정사: send a satellite to orbit just above the sun = 공전하도록 위성을 보내다 — to orbit이 목적을 표현. / however 삽입 (역접): ~, however, then ~ — 문중 콤마 삽입으로 S06과의 대조를 표시. / 비교급 부사 more accurately: know distances more accurately = 더 정확하게 알다 — 부사 accurately의 비교급.
【예증 2 — 위성을 보내려면 더 정밀해야】 목적이 태양 근접 위성이라면 같은 수치도 부족 — 더 정확한(more accurately) 값이 필요하다. ★ 두 예증의 대비로 '정밀함 = 상대적'이라는 결론 완성.

문장 05 · whether or not 주어절 / depend on + what절 / 과거분사 quoted
Whether or not the quoted number is “precise” therefore depends on what I'm intending to do with it.
수가 정밀한지는 그것으로 무엇을 하려는지에 달렸다.
Tier 1
whether or not 명사절 주어
Whether or not ~ is “precise” — 주어절(단수 취급 → depends). ✗ That or not → ✓ Whether or not(or not과 결합은 whether만).
Tier 1
depend on + 의문사절 what
depends on what I'm intending to do with it — do의 목적어 자리가 비어 있음 → what(that 불가). ✗ on that I'm intending → ✓ on what
Tier 2
과거분사 수식 quoted
the quoted number = 인용된 수 — 수동 → 과거분사. ✗ the quoting number → ✓ the quoted number
문장 06 · about + 의문사절 / 과거분사 후치수식
If I care only about what minute the sun will rise tomorrow, then the number quoted here is fine.

Tier 1
전치사 about + 의문사절
care only about what minute the sun will rise — 「what minute + S + V」 절이 about의 목적어(간접의문문 어순).
Tier 1
과거분사 후치수식 quoted
the number quoted here = 여기 인용된 수 — quoted가 뒤에서 수식. ✗ the number quoting here → ✓ quoted
Tier 4
if ~, then ~
If I care ~, then ~ is fine — 조건-결과를 then으로 명시.
문장 07 · 목적의 to부정사 / however 삽입 / 비교급 부사
If I want to send a satellite to orbit just above the sun, however, then I would need to know distances more accurately.
태양 근접 위성을 보내려면 거리를 더 정확히 알아야 한다.
Tier 1
목적의 to부정사
send a satellite to orbit just above the sun = 공전하도록 위성을 보내다. ✗ send a satellite orbiting → ✓ to orbit(목적).
Tier 2
however 문중 삽입
~, however, then ~ — 접속부사 however가 콤마 사이 삽입(S06과 대조).
Tier 3
비교급 부사 more accurately
know distances more accurately = 더 정확하게 알다 — 동사 수식은 부사(accurate 불가).
