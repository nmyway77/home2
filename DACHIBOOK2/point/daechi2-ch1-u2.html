📘 교재 핵심 정리 — UNIT 4 부가의문문 대치동 영문법 3300제 2 · CHAPTER 1 · 22~23쪽

부가의문문 · 예외적 부가의문문
4-1 부가의문문이란

평서문 뒤에 붙여 “그렇지?” / “그렇지 않니?” 하고 상대의 확인·동의를 구하는 짧은 의문문. 앞 문장과 쉼표(,)로 잇고 끝에 물음표를 쓴다.

You are a student, aren't you? / He doesn't like fish, does he?

만드는 3단계
  1. 긍정 ↔ 부정을 뒤집는다 (부정은 반드시 줄임말: isn't · doesn't · won't)
  2. 동사를 받는다 — be동사·조동사·have+p.p.는 그대로, 일반동사는 do / does / did
  3. 주어는 반드시 주격 대명사로 (Tom → he, this → it, There → there)
4-2 예외적 부가의문문
I am ~aren't I?
Let's ~ / Let's not ~shall we?
긍정 명령문 (Open ~ / Be ~ / Please ~)will you? (won't you? 가능)
부정 명령문 (Don't ~ / Never ~)will you? 만
There is/are ~isn't / aren't there?
never · hardly · few · little · no- 가 든 문장부정문으로 취급 → 긍정 부가의문문
대답하기

질문 모양과 상관없이 사실이 긍정이면 Yes + 긍정, 부정이면 No + 부정.

You don't like it, do you? — (안 좋아함) No, I don't. (우리말 “응”이지만 영어는 No)

※ 위 정리는 교재 UNIT의 내용을 표준 문법 기준으로 요약한 것입니다 (교재 원문 전재 아님).

🗂 정리 0. 출제 포인트 11 — 문제를 풀기 전에 하나씩 점검

포인트점검 질문기준
① be동사am · are · is · was · were인가 (진행형 · 수동태 포함)같은 be동사 그대로, 긍정 ↔ 부정만: He is sleeping, isn't he? / It was written, wasn't it?
② 조동사can · will · should · must · could · would가 있는가같은 조동사 그대로: will → won't · could → couldn't · must → mustn't
③ 일반동사be도 조동사도 아닌가, -s · -ed가 있는가do(현재) / does(-s) / did(과거) · used to → did
④ have + 명사 · tohave · has · had 뒤에 과거분사가 없는가「가지다 · ~해야 한다」 = 일반동사 → do / does / did (haven't ✗)
⑤ have + p.p.have · has · had 뒤에 과거분사가 있는가완료시제 → have / has / had 그대로 (did ✗) · 완료진행 · 완료수동도 맨 앞의 have
⑥ 주어대명사는 무엇인가, 중심 명사는 무엇인가this/that → it · these/those → they · A and I → we · There is → there · everyone/nobody → they(복수 동사) · -thing · 동명사 → it
⑦ 특수형I am · Let's · 명령문인가I am → aren't I / I was → wasn't I / Let's (not) → shall we / 명령문 → will you (부정 명령문은 will you만)
⑧ 거꾸로부가의문문의 동사가 무엇을 말해 주는가종류 · 시제 · 수를 그대로 보여 주고 긍정 · 부정만 반대: doesn't → -s 현재 / didn't → 과거 / hasn't → has p.p. / does he → doesn't
⑨ 대답사실이 긍정인가 부정인가질문 모양과 상관없이 사실 긍정 → Yes + 긍정 / 사실 부정 → No + 부정. 대답 동사 = 부가의문문의 동사
⑩ 긍정 · 부정not이 없어도 부정어가 있는가never · hardly · seldom · rarely · few · little · no- → 부정문 → 긍정 부가의문문 / a few · a little · un-/dis- 낱말 → 긍정문
⑪ 줄임말 · 시제's · 'd는 무엇의 줄임말인가, -s가 있는가's + 형용사·-ing → is / 's + p.p. → has / 'd like → would / 'd better → had / read · put에 -s 없음 → 과거

🗂 정리 1. 만드는 순서 3단계 — 앞 문장을 거꾸로 뒤집는다

단계확인할 것규칙예: Tom likes pizza, ________?
① 긍정 · 부정앞 문장이 긍정인가 부정인가긍정 → 부정 / 부정 → 긍정 (부정은 반드시 줄임말: isn't · doesn't)likes = 긍정 → 부정
② 동사be · 조동사 · 일반동사 · 완료 중 무엇, 시제는be · 조동사 · have(+p.p.) 그대로 / 일반동사 → do / does / didlikes = 일반동사 3인칭 단수 현재 → doesn't
③ 주어주어를 받는 대명사는명사 → 대명사 (명사를 다시 쓰지 않는다)Tom → he ⇒ doesn't he?

🗂 정리 2. 동사 받기 — have · had는 「뒤」를 본다

앞 문장의 동사받는 말예
be동사 / 진행형(be + -ing) / 수동태(be + p.p.)be동사 그대로He is sleeping, isn't he? / It was written, wasn't it?
조동사 can · will · should · must · could같은 조동사 (will → won't · could → couldn't)He can swim, can't he? / You will come, won't you?
일반동사 현재 / -s / 과거do / does / didYou like it, don't you? / She likes it, doesn't she? / They went, didn't they?
have / has / had + p.p. (완료 · 완료진행 · 완료수동)have / has / hadYou have finished, haven't you? / They have been waiting, haven't they?
have / has / had + 명사 (가지다)do / does / didShe has a cat, doesn't she? / He had a cold, didn't he?
have / has to · used todo / does / didWe have to go, don't we? / You used to live here, didn't you?
had better / 'd likehadn't / wouldn'tYou'd better go, hadn't you? / You'd like tea, wouldn't you?
★ 줄임말은 뒤를 본다: 's + 형용사 · 명사 · -ing → is (isn't) / 's + p.p. → has (hasn't) 'd + like → would (wouldn't) / 'd + better → had (hadn't) ★ 모양이 같은 과거형 read · put · cut · hit: 주어가 3인칭 단수인데 -s가 없으면 과거 → Tom read it, didn't he? / Tom reads it, doesn't he?

🗂 정리 3. 주어 받기 · 숨은 부정어

앞 문장의 주어대명사예
this · that · -thing · 동명사(-ing) · 사물 하나itThis is your bag, isn't it? / Swimming is fun, isn't it?
these · those · 복수명사 · everyone · nobodythey (everyone은 동사도 복수: aren't they)Everyone is here, aren't they? / Nobody came, did they?
A and I / You and A / A and Bwe / you / theyTom and I are friends, aren't we?
There is / are ~thereThere is a bank, isn't there?
명사 + 전치사구 (The books on the desk)중심 명사로 받는다The books on the desk are yours, aren't they?
부정어 (→ 긍정 부가의문문)긍정 (→ 부정 부가의문문)
never · hardly · seldom · rarely · few · little · no · nobody · nothing
She never eats it, does she? / There are few students, are there?		always · often · a few · a little · un- / dis- 낱말
There are a few students, aren't there? / He is unhappy, isn't he?

🗂 정리 4. 특수형 · 거꾸로 읽기 · 대답

앞 문장부가의문문틀린 형태
I am ~ / I am not ~ / I was ~aren't I? / am I? / wasn't I?amn't I ✗ · (I was) aren't I ✗
Let's ~ / Let's not ~shall we?will you ✗ · will we ✗ · shall not we ✗
긍정 명령문 (Open ~ / Be ~ / Please ~)will you? (won't you? 도 가능)do you ✗ · are you ✗
부정 명령문 (Don't ~ / Never ~)will you? 만won't you ✗ · do you ✗
부가의문문앞 문장의 동사예
don't / doesn't / didn't + 주어?일반동사 현재 / -s / 과거She likes it, doesn't she? / She liked it, didn't she?
isn't · wasn't … + 주어?같은 시제의 be(+ -ing / p.p.)He is sleeping, isn't he?
haven't / hasn't / hadn't + 주어?have / has / had + p.p.She has finished, hasn't she?
can't / won't … + 주어?같은 조동사 + 동사원형He can swim, can't he?
긍정 (does · did · is · has · can) + 주어?같은 동사의 부정형He doesn't like it, does he? / He hasn't come, has he?
대답: 질문이 don't you?든 do you?든 사실이 긍정이면 Yes + 긍정 / 사실이 부정이면 No + 부정 (✗ Yes, I don't · ✗ No, I do). 긍정 부가의문문(부정문 뒤)의 대답은 우리말과 반대: You don't like it, do you? — 안 좋아함 → No, I don't. (우리말 「응」) 대답의 동사 = 부가의문문의 동사: haven't you? → I have / I haven't (Yes, I do ✗ · Yes, I did ✗)
