화면이 안 켜지거나 메뉴를 못 찾으면: 전원 버튼 + 볼륨 아래(↓)를 길게 눌러 강제로 끈 뒤, 전원 + 볼륨 위(↑)로 복구 모드 진입 → Wipe data / factory reset → Reboot.

→ MC 설치 파일을 태블릿에 옮겨 설치 → 「목동서로영어」 다시 실행.
그러면 오른쪽 아래에 MC 버튼이 나타납니다.
