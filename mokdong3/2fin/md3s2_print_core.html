1. if 가정법 과거 — 현재 사실의 반대 / 현재·미래에 일어나지 않을 것 같은 일
If + 주어 + 동사의 과거형 ~, 주어 + 조동사 과거형(would, could, might) + 동사원형 … : '만일 ~라면, …할 텐데'
[직설법] As I am not a bird, I cannot fly to you. ⇒ [가정법] If I were (be) a bird, I could fly (fly) to you.
나는 새가 아니기 때문에 너에게 날아갈 수 없다. ⇒ 만약 내가 새라면 너에게 날아갈 수 있을 텐데.
[직설법] I don't know the recipe, so I cannot bake mom's birthday cake by myself. ⇒ If I knew (know) the recipe, I could bake (bake) mom's birthday cake by myself.
내가 요리법을 안다면, 엄마의 생일 케이크를 혼자서 만들 수 있을 텐데.
What would you do if you won (win) a million dollars?
백만 달러를 받는다면 뭐 하고 싶어?
* be동사는 인칭에 관계없이 "were" (구어체 1·3인칭은 was도 가능)
2. if 가정법 과거완료 — 과거 사실의 반대
If + 주어 + had p.p. ~, 주어 + 조동사 과거형 + have + p.p. … : '만일 ~했더라면, …했을 텐데'
[직설법] You didn't tell me about the problem, so I didn't help you. (부정) ⇒ If you had told me about the problem, I would have helped you. (긍정)
네가 나에게 그 문제를 얘기했더라면, 내가 너를 도왔을 텐데.
[직설법] The road was icy, so the accident happened. (긍정) ⇒ If the road hadn't been icy, the accident wouldn't have happened. (부정)
길이 얼지 않았다면 사고가 나지 않았을 텐데.
If I hadn't lost (lose) my wallet, I could have bought (buy) it.
내가 지갑을 잃어버리지 않았더라면, 그것을 살 수 있었을 텐데.

만약 그녀가 더 일찍 떠났더라면, 기차를 놓치지 않았을 텐데.
