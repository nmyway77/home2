✏️ be called + 명사: ~라고 불리다 (수동태) / 주격 관계대명사 that + was (선행사 a type of folk painting → 단수)

This kind of painting [S1] / is called [V1 수동태] / Munjado [C], / and / it [S2] / is [V2] / a type of folk painting [C] / (that was popular / in the late Joseon dynasty) [관계절 — 선행사 수식].

이런 종류의 그림은 / 불린다 / 문자도라고 / 그리고 / 그것은 / ~이다 / 민화의 한 종류 / (인기 있었던 / 조선 시대 후기에)

📘 핵심 문법
  • be called + 명사 : 능동 People call this kind of painting Munjado. (5형식 call + O + C) → 수동태로 바꾸면 목적격보어 Munjado가 be called 뒤에 그대로 남는다.
  • 주격 관계대명사 that : 선행사 a type of folk painting (사물) → that/which 가능. 관계절 속 동사는 선행사에 수일치 → 단수 was.
  • this kind of + 단수명사 + 단수동사 : This kind of painting is (are ✕).
  • 유사 예문: This dish is called bibimbap, and it is a food that is loved by many people. 이 음식은 비빔밥이라 불리고, 많은 사람에게 사랑받는 음식이다.
📌 주요 단어
  • kind (명) 종류 ≒ type, sort / (형) 친절한 — 다의어. this kind of = this type of = this sort of
  • folk (형) 민속의, 민간의 → folk painting 민화 / folk song 민요 / folk tale 민담
  • popular (형) 인기 있는 → popularity (명) 인기. be popular with ~에게 인기 있다
  • late (형) 후기의, 늦은 ↔ early 초기의 / (부) 늦게 → lately (부) 최근에 (뜻 주의!)
  • dynasty (명) 왕조, 시대 → the Joseon dynasty 조선 왕조
