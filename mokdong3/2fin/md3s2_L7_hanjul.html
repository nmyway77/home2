[본문 1] Living with Big Data — 도입: 온라인 서점의 책 추천

1
Have you ever visited an online bookstore and been surprised by the books that the store recommended for you?
▶ 당신은 온라인 서점을 방문해서, 그 서점이 당신에게 추천한 책들을 보고 놀란 적이 있는가?
📌 bookstore 서점 / be surprised by ~에 놀라다 / recommend 추천하다 ≒ suggest
✏️ Have you ever + p.p. ~? = 경험 (현재완료) / visited와 been surprised가 and로 병렬 / that ~ for you = books 수식 관계절
문장 분석 보기
✂️ 끊어 읽기

Have you ever [조동사 + S + 부사] / visited an online bookstore [p.p. ①] / and been surprised [p.p. ②] / by the books [행위자] / (that the store recommended for you) [books 수식]?

당신은 ~한 적이 있는가 / 온라인 서점을 방문하고 / 놀란 / 그 책들에 / 그 서점이 당신에게 추천한 → 현재완료(경험) 의문문

📘 핵심 문법
  • 현재완료 경험 : Have you ever + p.p. ~? "~해 본 적 있니?" ever는 have와 p.p. 사이에 온다. 대답은 Yes, I have. / No, I haven't.
  • 병렬 구조 : Have you ever 뒤에 visited와 been surprised 두 개의 p.p.가 and로 연결. 두 번째 동사도 have에 걸리므로 반드시 p.p. → and been surprised (and was surprised ✕ / and be surprised ✕).
  • be surprised by/at : 감정 동사 surprise(놀라게 하다)는 사람이 주어일 때 수동형 → 사람은 surprised, 사물은 surprising.
  • 목적격 관계대명사 that : the books that the store recommended (books를 목적어로 받음). that 생략 가능 → the books the store recommended for you.
  • 유사 예문: Have you ever been to Jeju and tried its black pork? 제주도에 가서 흑돼지를 먹어 본 적이 있니?
📌 주요 단어
  • visit (동) 방문하다 / (명) 방문 → visitor (명) 방문객
  • bookstore (명) 서점 = book + store
  • surprise (동) 놀라게 하다 / (명) 놀람 → surprised (형) 놀란 / surprising (형) 놀라운 / surprisingly (부) 놀랍게도
  • recommend (동) 추천하다 ≒ suggest → recommendation (명) 추천. recommend A for B: B에게 A를 추천하다
🔵 대명사 지칭

you = 글을 읽는 독자 / the store = an online bookstore

⚠️ 출제 포인트: ① been surprised (was / be ✕ — 병렬) ② surprised ↔ surprising ③ 관계대명사 that 자리(which 가능, what ✕ — 선행사 the books 있음) ④ 영작: "당신에게 추천한 책들" = the books that the store recommended for you.
2
Many of them looked interesting to you.
▶ 그것들(= 추천된 책들) 중 다수가 당신에게 흥미로워 보였다.
📌 many of ~ 중 다수 / look + 형 ~해 보이다 ≒ seem
✏️ look + 형용사 (interesting) = ~하게 보이다 (2형식) / to you = 당신에게
문장 분석 보기
✂️ 끊어 읽기

Many of them [S] / looked [V] / interesting [C] / to you [부사구].

그것들 중 다수가 / 보였다 / 흥미롭게 / 당신에게 → 2형식

📘 핵심 문법
  • 감각동사 look + 형용사 : look, sound, smell, taste, feel 뒤에는 형용사 보어 → looked interesting (interestingly ✕). 명사가 오면 look like + 명사.
  • many of + 복수 대명사/the 복수명사 → 복수동사. (현재라면 Many of them look ~)
  • interesting vs interested : 책이 흥미를 "주는" 쪽 → interesting. 사람이 흥미를 "느끼면" interested.
  • 유사 예문: The cake looked delicious, but it tasted too sweet. 그 케이크는 맛있어 보였지만 너무 달았다.
📌 주요 단어
  • many (형/대) 많은 / 다수 (셀 수 있는 명사) ↔ much (셀 수 없는 명사)
  • interesting (형) 흥미로운 → interest (명) 흥미 / (동) 흥미를 끌다 → interested (형) 흥미를 느끼는
🔵 대명사 지칭

them = the books that the store recommended for you (서점이 추천한 책들)

⚠️ 출제 포인트: ① looked interesting (interestingly ✕) ② interesting ↔ interested ③ them이 가리키는 것 서술형: "the books (that) the store recommended".
3
So how did the bookstore know what you liked?
▶ 그렇다면 그 서점은 당신이 무엇을 좋아하는지 어떻게 알았을까?
📌 so 그렇다면 ≒ then / what you liked 당신이 무엇을 좋아하는지
✏️ what you liked = 간접의문문 (의문사+주어+동사 어순), know의 목적어
문장 분석 보기
✂️ 끊어 읽기

So [접속사] / how [의문사] / did the bookstore know [조동사 + S + V] / what you liked [O : 간접의문문]?

그렇다면 / 어떻게 / 그 서점은 알았을까 / 당신이 무엇을 좋아하는지

📘 핵심 문법
  • 간접의문문 = 의문사 + 주어 + 동사 : 직접의문문 What did you like? → 문장 속에 들어가면 what you liked (did 사라지고, 동사에 시제 반영). what did you like ✕.
  • 바깥 문장은 일반 의문문 어순: how did the bookstore know (조동사 did + 주어 + 동사원형).
  • 여기 what은 "무엇"(의문사)으로 해석 → 간접의문문. "~하는 것"으로 해석하면 관계대명사 what. 이 문장은 "무엇을 좋아하는지"가 자연스럽다.
  • 유사 예문: Do you know where she lives? 그녀가 어디 사는지 아니? (where does she live ✕)
📌 주요 단어
  • so (접) 그래서, 그렇다면 (화제를 이어 질문할 때)
  • know (동) 알다 (know-knew-known) → knowledge (명) 지식
🔵 대명사 지칭

you = 독자 / the bookstore = 1번의 an online bookstore

⚠️ 출제 포인트: 간접의문문 어순 배열 — how / did / the bookstore / know / what / you / liked. 감점: what did you like / what you did like.
💡 글의 흐름: 1~3번 질문으로 호기심 유발 → 4번에서 답(빅데이터) 제시.

This is all possible because of big data.
▶ 이것(= 서점이 취향을 아는 것)은 모두 빅데이터 때문에 가능하다.
📌 possible 가능한 ↔ impossible / because of ~ 때문에 ≒ thanks to, due to
✏️ because of + 명사(구) / because + 주어+동사 (절) 구별!
문장 분석 보기
✂️ 끊어 읽기

This [S] / is [V] / all [부사: 모두] / possible [C] / because of big data [이유].

이것은 / 모두 가능하다 / 빅데이터 때문에 → 2형식

📘 핵심 문법
  • because of + 명사(구) vs because + 주어 + 동사 : because of big data (명사) / because the store analyzed data (절). because big data ✕.
  • 같은 뜻 전치사: thanks to(~ 덕분에, 긍정), due to, owing to.
  • all의 위치: be동사 뒤에서 "모두, 전부"를 강조.
  • 유사 예문: The game was canceled because of the rain. = ~ because it rained.
📌 주요 단어
  • possible (형) 가능한 ↔ impossible → possibility (명) 가능성 / possibly (부) 아마
  • big data (명) 빅데이터 (셀 수 없는 명사 취급 → is)
🔵 대명사 지칭

This = 서점이 당신이 좋아하는 것을 알고 책을 추천하는 것 (1~3번 내용 전체)

⚠️ 출제 포인트: because of ↔ because 선택 / This가 가리키는 내용 서술형 / 글의 소재 = big data (첫 등장 문장).

[What is big data?] 빅데이터는 무엇인가? — 정의

5
Big data is data sets that are very big and complex.
▶ 빅데이터는 매우 크고 복잡한 데이터의 집합이다.
📌 data set 데이터 집합 / complex 복잡한 ≒ complicated
✏️ that = 주격 관계대명사 (선행사 data sets, 복수 → are)
문장 분석 보기
✂️ 끊어 읽기

Big data [S] / is [V] / data sets [C] / (that are very big and complex) [data sets 수식].

빅데이터는 / ~이다 / 데이터 집합 / 매우 크고 복잡한 → 2형식

📘 핵심 문법
  • 주격 관계대명사 that : 관계절 안에서 주어 역할 → 뒤에 바로 동사(are). 주격은 생략 불가.
  • 관계절 동사의 수 = 선행사의 수 : 선행사 data sets(복수) → are. (주절 주어 Big data는 단수 → is)
  • which로 바꿔 쓸 수 있음 (사물 선행사).
  • 유사 예문: A dictionary is a book that has the meanings of words.
📌 주요 단어
  • data (명) 데이터, 자료 (원래 datum의 복수형이지만 보통 셀 수 없는 명사로 씀)
  • set (명) 집합, 세트 / (동) 놓다 (set-set-set)
  • complex (형) 복잡한 ≒ complicated ↔ simple → complexity (명) 복잡성
🔵 대명사 지칭

that = data sets (관계대명사)

⚠️ 출제 포인트: ① 빅데이터의 정의 문장 (내용 일치·영영풀이) ② that are (is ✕ — 선행사 복수) ③ 단어 complex의 뜻.
6
As information and communication technology develops, the amount of data we have is getting much greater than before.
▶ 정보 통신 기술이 발달함에 따라, 우리가 갖고 있는 데이터의 양이 이전보다 훨씬 더 많아지고 있다.
📌 develop 발달하다 ≒ grow, advance / the amount of ~의 양 / much + 비교급 훨씬 ≒ far, even, a lot
✏️ As + 절 = ~함에 따라 / data (which) we have = 목적격 관계대명사 생략 / much = 비교급 강조 (훨씬)
문장 분석 보기
✂️ 끊어 읽기

As information and communication technology develops [부사절: ~함에 따라], / the amount of data [S] / (we have) [data 수식] / is getting [V] / much greater [C] / than before.

정보 통신 기술이 발달함에 따라 / 데이터의 양이 / 우리가 가진 / 되어 가고 있다 / 훨씬 더 많게 / 이전보다

📘 핵심 문법
  • 접속사 as = ~함에 따라 (비례·변화) : 주절에 get/become + 비교급이 자주 같이 온다. as의 다른 뜻: ~할 때, ~ 때문에, ~처럼.
  • 목적격 관계대명사 생략 : data (which/that) we have — 명사 뒤에 "주어 + 동사"가 바로 오면 생략된 것.
  • 주어 = the amount (단수) → is getting. of data we have는 꾸밈말.
  • 비교급 강조 much / far / even / still / a lot + 비교급 = 훨씬. very greater ✕.
  • get + 비교급 = 점점 ~해지다 (진행형으로 변화 강조).
  • 유사 예문: As you grow older, you become much wiser. 나이가 들수록 훨씬 더 현명해진다.
📌 주요 단어
  • information (명) 정보 (셀 수 없음 → informations ✕) ← inform (동) 알리다
  • communication (명) 의사소통, 통신 ← communicate (동)
  • technology (명) 기술 → technological (형)
  • develop (동) 발달하다, 개발하다 → development (명) 발달 / developed (형) 선진의
  • amount (명) 양 (셀 수 없는 명사) ↔ number (셀 수 있는 명사의 수)
🔵 대명사 지칭

we = 우리(사람들 일반)

⚠️ 출제 포인트: ① much greater (very ✕) ② is getting (are ✕ — 주어 the amount) ③ As의 의미(~함에 따라) ④ amount ↔ number 구별.

This is mainly because almost everything that we do online leaves a trace.
▶ 이것(= 데이터 양이 늘어나는 것)의 주된 이유는 우리가 온라인상에서 하는 거의 모든 것들이 흔적을 남기기 때문이다.
📌 mainly 주로 ≒ mostly, chiefly / leave a trace 흔적을 남기다 / trace 흔적 ≒ mark, track
✏️ This is because + 주어+동사 = 이는 ~ 때문이다 / that = 목적격 관계대명사 (everything 수식) / 주어 everything(단수) → leaves
문장 분석 보기
✂️ 끊어 읽기

This is mainly because [이는 주로 ~ 때문이다] / almost everything [S'] / (that we do online) [everything 수식] / leaves [V'] / a trace [O'].

이는 주로 ~ 때문이다 / 거의 모든 것이 / 우리가 온라인에서 하는 / 남기다 / 흔적을

📘 핵심 문법
  • This is because + 원인 (이는 ~ 때문이다) ↔ This is why + 결과 (그래서 ~이다). 앞 문장이 결과, because 뒤가 원인.
  • 목적격 관계대명사 that : everything that we do (do의 목적어). -thing으로 끝나는 선행사 뒤에는 that을 즐겨 쓴다. 생략 가능.
  • everything = 단수 → leaves (leave ✕). 관계절 we do 속 do에 속지 말 것.
  • almost는 everything/all/every를 꾸밈 : almost everything (most everything ✕, almost of ✕).
  • 유사 예문: I was late. This is because the bus didn't come.
📌 주요 단어
  • mainly (부) 주로 ≒ mostly, chiefly ← main (형) 주된
  • online (부/형) 온라인으로 / 온라인의 ↔ offline
  • leave (동) 남기다, 떠나다 (leave-left-left)
  • trace (명) 흔적 ≒ mark, track / (동) 추적하다
🔵 대명사 지칭

This = 우리가 가진 데이터의 양이 이전보다 훨씬 많아지고 있는 것 (6번 내용)

⚠️ 출제 포인트: ① 수일치 everything ~ leaves ② This is because ↔ This is why ③ 데이터 양이 늘어난 이유 서술형: "거의 모든 온라인 활동이 흔적을 남기기 때문" ④ 배열: almost everything / that / we do online / leaves / a trace.

✦ Big data, when analyzed, helps us predict the future and make better decisions.
(빅데이터는 분석되면 미래를 예측하고 더 나은 결정을 내리도록 돕는다.)

💡 빅데이터란? — '발자국 모으기'

  • 온라인에서 하는 거의 모든 일(사진 올리기, 물건 사기)이 흔적(trace)을 남김 → 이 흔적이 쌓인 거대한 데이터 집합 = 빅데이터
  • 비유: 눈 위를 걸으면 발자국이 남듯, 인터넷 위를 걸으면 데이터 발자국이 남는다
  • 핵심 조건: 모으기(collecting)만으론 부족 → 전문가가 분석(analyze)해서 의미 있는 결과를 도출해야 함

⚠️ 3가지 활용 예시 — 예측(predict)이 공통 키워드

  • ① 질병 예측: 독감철 약 구매↑ + 증상 검색↑ → 독감 확산 예측
  • ② 스포츠: 독일 대표팀이 선수 데이터(달린 거리, 공 소유 시간)로 데이터베이스 구축 → 2014 월드컵 우승
  • ③ 범죄 예방: 유형·시간·장소 데이터로 범죄 다발 지역 지도 → 그 지역·시간에 경찰 집중

🎯 결론 — 앞으로는?

  • 빅데이터는 이미 세계를 크게 바꿨다 (has already changed)
  • 앞으로 어디로 갈지는 아무도 모르지만, 전문가들은 '더욱 더 중요한 역할(more and more important role)'을 할 것이라는 데 동의
