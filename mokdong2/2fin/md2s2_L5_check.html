본문의 (가), (나)에 들어갈 말을 〈보기〉에서 고르고, 어디에도 들어갈 수 없는 것 하나를 고른 뒤 그 이유를 쓰시오. (표적: 연결어 배제형)
〈보기〉 ( As / For example / However / For instance )
(가) As　(나) For example (≒ For instance)
▶ 어디에도 들어갈 수 없는 것: However　이유: (가)는 '~하다시피', (나)는 예시 제시이므로 역접은 어디에도 맞지 않음
정답·해설 보기
정답 (가) As (you can see) (나) For example (≒ For instance 가능) ▶ 불가: However — (가)는 '~하다시피', (나)는 예시 제시이므로 역접은 어디에도 맞지 않음
📌 근거
  • (가) (가) you can see, he created a green tree ... → As you can see = 보시다시피. 뒤에 주어+동사(you can see)가 붙는 접속사 자리라 As만 가능. (23번)
  • (나) His gum paintings often carry personal messages ... (나), the one over here is a happy birthday wish for a loved one. → 일반 설명 뒤 구체적 사례 → For example = For instance. (45번)
  • However(하지만)는 앞뒤가 반대 내용일 때 쓰는 역접. (가)·(나) 모두 앞 내용과 같은 방향으로 이어지므로 들어갈 곳이 없다.
⚠️ 함정: ★ For instance는 (나)에 들어갈 수 있으므로 '배제 대상'이 아니다. "남는 것이 For instance"라고 답하면 오답 — 배제할 것은 However 하나.
