UNIT01–04

동사 활용 연습

어법 해설 · 01~04 · 240문항
01~04는 동사의 형태를 바꾸는 기초 연습입니다. 3인칭 단수 현재형과 규칙 과거형(01) → 불규칙 동사의 과거형 · 과거분사형(02, 03) → -ing형(04) 순서입니다. 뒤에 나오는 시제 · 수동태 · 가정법 전환은 모두 이 네 가지 형태를 정확히 쓸 수 있어야 풀 수 있습니다.

13인칭 단수 현재형 — -s / -es

동사의 끝만드는 법예
대부분의 동사-sclaim → claims, wipe → wipes
-s, -x, -z, -ch, -sh-esmess → messes, scratch → scratches, cherish → cherishes
자음 + yy → i + esimply → implies, modify → modifies, supply → supplies
모음 + y-sannoy → annoys

2규칙 동사의 과거형 · 과거분사형 — -ed 철자 주의

동사의 끝만드는 법예
대부분의 동사-edassert → asserted, scold → scolded
-e-dacquire → acquired, delete → deleted
자음 + yy → i + edimply → implied, supply → supplied
모음 + y-edannoy → annoyed
단모음 + 단자음
(1음절, 또는 강세가 끝 음절)		자음을 겹치고 -edgrip → gripped, excel → excelled
함정 ① 강세가 앞 음절에 있으면 자음을 겹치지 않습니다: alter → altered, hinder → hindered. ② 모음이 두 개이면 겹치지 않습니다: conceal → concealed, peel → peeled. ③ handicap → handicapped, kidnap → kidnapped, worship → worshipped는 강세가 앞에 있어도 p를 겹쳐 씁니다.

3불규칙 동사 — 네 가지 유형 내신 빈출

유형특징예 (원형 - 과거형 - 과거분사형)
A-A-A세 형태가 같다cut - cut - cut / put - put - put / let, hit, hurt, quit, cost, cast, burst, spread, upset, bet
A-B-B과거형 = 과거분사형find - found - found / buy - bought - bought / teach - taught - taught / keep - kept - kept / lead - led - led
A-B-A원형 = 과거분사형come - came - come / become - became - become / run - ran - run
A-B-C세 형태가 다르다go - went - gone / eat - ate - eaten / write - wrote - written / ring - rang - rung / fly - flew - flown

뜻에 따라 변화가 달라지는 동사

원형뜻과거형 - 과거분사형
lie눕다, 놓여 있다 (자동사)lay - lain
거짓말하다lied - lied
lay놓다, (알을) 낳다 (타동사)laid - laid
hang걸다, 매달다hung - hung
교수형에 처하다hanged - hanged
bear낳다, 참다bore - born(태어나다: be born) / borne(그 밖의 뜻)
함정 형태가 겹치는 동사를 구별합니다. find - found - found(찾다) / found - founded - founded(설립하다), fall - fell - fallen(떨어지다) / fell - felled - felled(베어 넘어뜨리다), rise - rose - risen(오르다) / raise - raised - raised(올리다).

4-ing형 만들기

동사의 끝만드는 법예
대부분의 동사-ingbark → barking, annoy → annoying, imply → implying
소리 나지 않는 -ee를 빼고 -ingacquire → acquiring, wipe → wiping
-ieie → y + inglie → lying, tie → tying
단모음 + 단자음자음을 겹치고 -inggrip → gripping, shed → shedding, excel → excelling
-ick를 넣고 -ingmimic → mimicking, picnic → picnicking
-ed를 붙일 때는 「자음 + y」의 y를 i로 고치지만, -ing를 붙일 때는 y를 그대로 둔다
modify → modified / modifying

✓시험 직전 점검

  1. -s, -x, -ch, -sh로 끝나면 -es. 자음 + y는 -ies / -ied.
  2. grip, excel처럼 단모음 + 단자음(강세 음절)이면 자음을 겹친다. gripped, excelled.
  3. lie(눕다) - lay - lain / lay(놓다) - laid - laid / lie(거짓말하다) - lied - lied.
  4. hang(걸다) - hung - hung / hang(교수형) - hanged - hanged.
  5. -ie → -ying(lying, tying), -ic → -icking(mimicking, picnicking).

3수동태의 시제 — be동사만 바뀝니다 내신 빈출

능동태의 목적어(a picture)를 주어로 옮기고, 동사를 be + 과거분사로 바꾸고, 원래 주어를 by + 목적격으로 뒤에 둡니다. 시제는 be동사에만 나타나고 과거분사 drawn은 변하지 않습니다.

시제형태예
—현재 (보기)am / are / is + p.p.A picture is drawn by me.
A과거was / were + p.p.A picture was drawn by me.
B미래will be + p.p.A picture will be drawn by me.
C현재진행am / are / is + being + p.p.A picture is being drawn by me.
D과거진행was / were + being + p.p.A picture was being drawn by me.
  • be동사는 새 주어에 맞춥니다. A picture(단수) → is / was, Pictures(복수) → are / were. 능동태의 주어(I, he, they)와는 상관없습니다.
  • by 뒤는 목적격입니다. I → me, he → him, she → her, we → us, they → them. you와 it은 형태가 같습니다.

✓시험 직전 점검

  1. draw - drew - drawn - drawing.
  2. He / She / It만 is, has. I는 am, was, have.
  3. will 뒤는 원형: will draw, will be drawing, will have drawn.

문장 형식별 수동태 전환

어법 해설 · 09~11 · 68문항
09~11은 능동태 문장을 수동태로 바꾸는 연습입니다. 3형식(09) → 4형식(10) → 5형식(11) 순서로, 문장의 형식에 따라 "무엇이 주어로 나가고 무엇이 남는가"가 달라집니다.

13형식의 수동태 09

  1. 능동태의 목적어를 주어로 옮깁니다. 목적격은 주격으로 바꿉니다(me → I, her → She, us → We, them → They).
  2. 동사를 be + 과거분사로 바꿉니다. be동사의 시제는 원래 동사에, 수는 새 주어에 맞춥니다.
  3. 능동태의 주어를 by + 목적격으로 뒤에 둡니다.

She hates me. → I am hated by her.현재 · 주어 I → am

We played the violin. → The violin was played by us.과거 · 주어가 단수 → was

타동사구 — 한 덩어리로 옮깁니다

She took care of me. → I was taken care of by her.of를 빠뜨리지 않는다

that절이 목적어일 때 — 두 가지 수동태 내신 빈출

방법형태예: They said that you were unfair.
① 가주어 ItIt + be p.p. + that절It was said that you were unfair.
② that절의 주어를 주어로주어 + be p.p. + to부정사You were said to be unfair.
함정 that절의 시제가 주절보다 앞서면 완료부정사(to have p.p.)를 씁니다. We think that they were right. → They are thought to have been right.

2타동사구의 수동태

「동사 + 전치사」, 「동사 + 부사 + 전치사」, 「동사 + 명사 + 전치사」는 한 덩어리의 타동사로 봅니다. 전치사를 빠뜨리지 않고 그 뒤에 by를 씁니다.

Tom laughed at me. → I was laughed at by Tom.laugh at

They look down on us. → We are looked down on by them.look down on

You must take care of him. → He must be taken care of by you.take care of

  3. 다시 의문문으로 만듭니다. be동사나 첫 번째 조동사를 주어 앞으로 보냅니다. → Is an essay read by him?

✓시험 직전 점검

  1. 진행 수동태 be being p.p. / 완료 수동태 have been p.p.
  2. 조동사 + be + p.p. / 조동사 + have been + p.p.

UNIT14–15

가정법 전환

어법 해설 · 14~15 · 48문항
14~15는 사실을 말하는 직설법 문장을 가정법으로 바꾸는 연습입니다. 가정법 과거 · 과거완료(14) → I wish / ~이 없다면(15) 순서입니다. 가정법은 사실과 반대로 말하는 것이므로, 바꿀 때마다 시제를 한 단계 뒤로, 긍정과 부정을 반대로 합니다.

1직설법 → 가정법 내신 빈출

직설법가정법If절주절
현재
(As ~ 현재, ~ 현재)		가정법 과거
현재 사실의 반대		If + 주어 + 과거형
(be동사는 were)		주어 + would / could + 동사원형
과거
(As ~ 과거, ~ 과거)		가정법 과거완료
과거 사실의 반대		If + 주어 + had + p.p.주어 + would / could + have + p.p.

바꾸는 순서

  1. 접속사 As, Since, Because를 If로 바꿉니다. A, so B이면 A가 If절이 됩니다.
  2. 동사의 시제를 한 단계 뒤로 보냅니다. 현재 → 과거, 과거 → had p.p.
  3. 긍정은 부정으로, 부정은 긍정으로 바꿉니다.
  4. 주절에 조동사가 없으면 would를 넣고, can이 있으면 could로 씁니다.

As I am not a bird, I can't fly to you.직설법 현재

If I were a bird, I could fly to you.가정법 과거

As I was not a bird, I couldn't fly to you.직설법 과거

If I had been a bird, I could have flown to you.가정법 과거완료

함정 have의 가정법 과거완료는 had had입니다. As I didn't have a job → If I had had a job. 앞의 had는 조동사, 뒤의 had는 have의 과거분사입니다.

2I wish 가정법 15-A

I'm sorry (that) ~, It's a pity (that) ~는 사실에 대한 유감이고, I wish ~는 그 반대를 바라는 말입니다. 긍정과 부정을 뒤집고 시제를 한 단계 뒤로 보냅니다.

직설법가정법예
I'm sorry + 현재I wish + 가정법 과거I'm sorry I am not a bird. → I wish I were a bird.
I'm sorry I can't read fast. → I wish I could read fast.
I'm sorry + 과거I wish + 가정법 과거완료I'm sorry I didn't do my best. → I wish I had done my best.
It's a pity I couldn't buy it. → I wish I could have bought it.
I was sorry ~I wished ~I was sorry I had not visited her hometown. → I wished I had visited her hometown.
주절의 시제는 그대로 옮긴다 — I'm sorry → I wish / I was sorry → I wished

함정 But for와 Without은 형태가 같으므로 주절의 동사를 보고 시제를 정합니다. 주절이 couldn't do이면 If it were not for, couldn't have passed이면 If it had not been for로 바꿉니다.

✓시험 직전 점검

  1. 직설법 현재 → If + 과거형(were), would / could + 원형.
  2. 직설법 과거 → If + had p.p., would / could + have p.p.
  3. 긍정과 부정을 반드시 뒤집는다.
  4. I'm sorry + 현재 → I wish + 과거형 / I'm sorry + 과거 → I wish + had p.p.
  5. If it were not for = Were it not for = But for = Without.
  6. If it had not been for = Had it not been for = But for = Without.

화법 전환

어법 해설 · 16~18 · 36문항
16~18은 직접화법을 간접화법으로 바꾸는 연습입니다. 평서문(16) → 의문사가 없는 의문문(17) → 의문사가 있는 의문문(18) 순서이고, 각각 전달동사가 현재(say)일 때와 과거(said)일 때로 나뉘어 있습니다. 같은 문장을 두 번 바꾸어 보면서 인칭 전환과 시제 일치를 따로따로 익히는 구성입니다.

  2. 의문문: ask (+ 사람) + if(whether) 또는 의문사 + 주어 + 동사.
