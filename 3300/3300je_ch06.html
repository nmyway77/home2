UNIT12

비교급과 최상급의 형태

어법 해설 · EXERCISE A~C · 43문항
Unit 12는 비교급과 최상급을 만드는 법입니다. EXERCISE A는 -er / -est, B는 -er / -est와 more / most의 구별, C는 불규칙 변화입니다. 형태를 틀리면 Unit 13의 문장 전환 문제도 모두 틀리게 되므로 먼저 정확히 익혀야 합니다.

1-er / -est를 붙이는 규칙 변화

1음절 단어는 대부분 원급에 -er(비교급), -est(최상급)를 붙입니다. 끝 철자에 따라 붙이는 방법이 조금씩 다릅니다.

끝 철자방법예
대부분-er / -estcold - colder - coldest
young - younger - youngest
-e로 끝남-r / -st만wide - wider - widest
단모음 + 단자음끝 자음을 한 번 더 쓰고 -er / -estthin - thinner - thinnest
자음 + yy를 i로 바꾸고 -er / -estpretty - prettier - prettiest
함정 자음을 겹쳐 쓰는 것은 모음 글자가 하나일 때뿐입니다. thin, big, hot은 겹쳐 쓰지만 모음 글자가 둘인 sweet, cheap, keen, cool, poor, loud, great는 겹쳐 쓰지 않습니다(sweetter, cooller). 또 w로 끝나는 low는 겹쳐 쓰지 않습니다(lower).

22음절 단어 — -er / -est를 붙이는 경우

2음절 단어 가운데 아래 철자로 끝나는 것은 -er / -est를 붙입니다. EXERCISE B에 나오는 단어들입니다.

끝 철자예
-ypretty - prettier - prettiest
-ownarrow - narrower - narrowest
-erbitter - bitterer - bitterest
tender - tenderer - tenderest
-ureobscure - obscurer - obscurest

-er로 끝나는 단어에 다시 -er을 붙이므로 철자가 bitterer, tenderer처럼 됩니다.

3more / most를 쓰는 경우 내신 빈출

종류예
3음절 이상expensive - more expensive - most expensive
important - more important - most important
-ful, -less, -ous 등으로 끝나는 2음절careful - more careful - most careful
분사에서 온 형용사 (-ing, -ed)exciting - more exciting - most exciting
형용사 + ly로 된 부사quickly - more quickly - most quickly
a-로 시작하는 서술 형용사alive - more alive - most alive
함정 -ly로 끝난다고 모두 more를 쓰는 것은 아닙니다. quickly는 quick + ly로 만든 부사라서 more quickly이지만, early처럼 -ly가 원래 철자의 일부인 단어는 earlier입니다. 또 -er과 more를 함께 쓰는 이중 비교는 항상 틀립니다: more faster, more smarter.

4불규칙 변화 내신 빈출

원급비교급최상급뜻
good / wellbetterbest좋은 / 건강한, 잘
bad / illworseworst나쁜 / 아픈
many / muchmoremost(수가) 많은 / (양이) 많은
littlelessleast(양이) 적은

원급은 둘인데 비교급·최상급은 하나로 같아지는 것이 특징입니다. 그래서 better가 문장에서 good의 비교급(형용사)인지 well의 비교급(부사)인지는 꾸미는 대상을 보고 판단합니다(기출응용 16번).

5뜻에 따라 형태가 둘인 단어 내신 빈출

원급뜻비교급최상급
far거리 (더 먼)fartherfarthest
정도 (더 나아간, 추가의)furtherfurthest
late시간 (더 늦은, 최신의)laterlatest
순서 (후자의, 마지막의)latterlast
old나이, 오래됨olderoldest
손위 (형제 사이)eldereldest
  • the latest news는 '최신 뉴스', the last news는 '마지막 뉴스'입니다.
  • elder는 my elder brother처럼 명사 앞에서만 쓰고, than과 함께 쓰지 않습니다. 나이를 비교할 때는 older than입니다.

시험 직전 점검

  1. -e → -r / -st (wider), 단모음 + 단자음 → 자음 겹침 (thinner), 자음 + y → -ier (prettier).
  2. 모음 글자가 둘이면 자음을 겹치지 않는다: sweeter, cheaper, cooler, greater.
  3. 3음절 이상, -ful, -ing형, 형용사 + ly 부사, a-형용사 → more / most.
  4. good·well – better – best / bad·ill – worse – worst / many·much – more – most / little – less – least.
  5. farther(거리)·further(정도) / later·latest(시간)·latter·last(순서) / older(나이)·elder(손위).

UNIT13

비교의 형식

어법 해설 · EXERCISE A~D · 29문항
Unit 13은 비교 문장을 만드는 법입니다. 원급 비교(A) → 비교급(B) → 최상급(C) → 강조(D) 순서이고, 대부분 문장 전환 문제이므로 공식을 그대로 익혀 두는 것이 가장 빠릅니다.

1원급 비교 : as ~ as 내신 빈출

as + 원급 + as : ~만큼 …한 (둘이 같다)
not as(so) + 원급 + as : ~만큼 …하지 않은 (앞의 것이 덜하다)

My cat has lived here as long as I.내 고양이는 나만큼 오래 여기서 살았다.

I am not so tall as he.나는 그만큼 키가 크지 않다.

  • as와 as 사이에는 반드시 원급이 옵니다. as taller as
  • 부정문에서만 앞의 as를 so로 바꿀 수 있습니다. 긍정문에서는 as ~ as만 씁니다.
  • 뒤의 as 다음에는 명사·대명사뿐 아니라 「주어 + 동사」도 올 수 있습니다. not as big as I expected(내가 예상한 만큼), not so tall as I thought he would be(내가 생각한 만큼)

as ~ as possible

as + 원급 + as possible = as + 원급 + as + 주어 + can(could) : 가능한 한 ~하게

Come back home as early as possible.가능한 한 일찍 집으로 돌아오너라.

He walked as slowly as he could.그는 가능한 한 느리게 걸었다. (과거 walked → could)

as cunning as a fox(여우처럼 간사한)처럼 as ~ as는 '~처럼 …한'이라는 비유 표현에도 쓰입니다.

2비교급 + than, 그리고 원급 부정과의 전환 내신 빈출

A is not as + 원급 + as B = B is + 비교급 + than A
주어와 비교 대상의 자리가 서로 바뀐다.

Ji-na is not as tall as Jeong-won. = Jeong-won is taller than Ji-na.지나는 정원이만큼 키가 크지 않다. = 정원이는 지나보다 키가 크다.

This quiz is not as difficult as that one. = That quiz is more difficult than this one.이 퀴즈는 저 퀴즈만큼 어렵지 않다. = 저 퀴즈가 이 퀴즈보다 더 어렵다.

  • 전환할 때 Unit 12의 형태 규칙을 그대로 적용합니다: tall → taller, pretty → prettier, popular → more popular, difficult → more difficult.
  • 동사를 꾸미는 '더 (많이)'는 more 또는 better입니다. I like history more than math.

구문뜻예문

  3. A is not as ~ as B = B is 비교급 than A.

핵심 어법① 비교급 강조(훨씬): much, even, still, far, a lot + 비교급.

  2. veryYou are the very cleverest student of all the students.

1선행사 the student는 사람 → which인 ④⑤ 탈락.
2'최고 점수' → 최상급 highest. 비교급 higher인 ② 탈락.
3최상급 앞에 the가 있어야 한다. ① 탈락. → who got the highest grade
선지 분석
  • ①✗최상급 highest 앞에 the가 없다.
  • ②✗higher는 비교급. '최고'의 뜻이 아니고 관사도 없다.
  • ③○사람 선행사 who + the + 최상급.
  • ④✗which는 사물 선행사에 쓴다.
  • ⑤✗which도 틀렸고 원급 high도 뜻이 맞지 않는다.
해석담임 선생님은 최고 점수를 받은 학생에게 선물을 주기로 결정하셨다.

기출
23. 대화의 빈칸에 들어갈 표현 중 적절하지 않은 것을 고르세요.
A: Which movie do you like best?
B: The Lord of the Rings. What about you?
A: Me, too. ________.
① I like it the best ② Nothing can be better than it ③ There's nothing I like more than it ④ I like it more than any other movies ⑤ No movie is better than it
23번 정답 · 상세 해설 펼치기
ANSWER · 정답
④ any other movies (✗) → any other movie
출제 포인트비교급 + than any other + 단수명사. 복수명사를 쓰려면 all the other + 복수명사.
풀이 순서
1다섯 선지 모두 '그 영화를 가장 좋아한다'는 최상급의 뜻을 나타내려 한다.
2①은 최상급, ②③⑤는 Nothing / No ~ 비교급 than으로 어법에 맞다.
3④ any other 뒤에 복수 movies가 왔다 → 단수 movie여야 한다.
선지 분석
  • ①○like ~ the best. 최상급.
  • ②○Nothing ~ 비교급 than.
  • ③○There's nothing ~ 비교급 than.
  • ④✗any other + 단수명사 → any other movie.
  • ⑤○No + 단수명사 ~ 비교급 than.
해석A: 너는 어떤 영화를 가장 좋아하니? / B: 반지의 제왕이야. 너는? / A: 나도 그래. — ① 나는 그것을 가장 좋아해. ② 그것보다 더 좋은 것은 있을 수 없어. ③ 내가 그것보다 더 좋아하는 것은 없어. ④ 나는 다른 어떤 영화보다 그것을 좋아해. ⑤ 어떤 영화도 그것보다 낫지 않아.
