01
Mirror neurons are the hardware of empathy, and so what would make more sense than to look and see which animals possess these cells?
🔊
거울 뉴런은 공감의 하드웨어이다. 그러니 어떤 동물이 이 세포를 지니고 있는지 살펴보는 것보다 더 이치에 맞는 일이 무엇이겠는가?
📌mirror neuron거울 뉴런(남의 행동을 보면 내 뇌도 따라 반응하는 신경 세포)hardware하드웨어, 장치 (↔ software)empathy공감 (→ empathize 공감하다 / sympathy '동정'과 혼동 주의)make sense이치에 맞다, 말이 되다 ('감각을 만들다' 직역 금지)possess지니다, 소유하다 (≒ have, own)cell세포 (다의어: ① 세포 ② 감방)
📐 문장 구조도
✏️ 문법수사의문문 what would make more sense than ~: what would make more sense than to look and see ~? = ~보다 더 이치에 맞는 게 뭐가 있겠는가 — '~가 가장 당연하다'는 강조. / 간접의문문 (의문사 + S + V): see which animals possess these cells = 어떤 동물이 이 세포를 지니는지 — see의 목적어. / 지시어 these cells: these cells = 앞의 mirror neurons를 되받는 표현.
【도입 — 공감의 '부품'을 가진 동물 찾기】 거울 뉴런 = 남의 행동·감정을 내 것처럼 비춰 주는 뇌 속 부품. 공감의 하드웨어가 이것이라면, '어떤 동물이 이 부품을 달고 있나?' 확인하는 게 당연한 다음 순서라는 수사적 질문이다. ★ 수사의문문 = 강한 긍정(가장 당연하다).
02
And this is exactly where modern research now stands: all researchers know so far is that apes possess mirror neurons.
🔊
그리고 이것(= 어떤 동물이 거울 뉴런을 갖는지 확인하는 일)이 바로 현대 연구가 지금 서 있는 지점이다. 즉, 연구자들이 지금까지 아는 전부는 유인원이 거울 뉴런을 지니고 있다는 것이다.
📌exactly정확히, 바로stand(상황이) ~한 상태에 있다 (다의어: ① 서다 ② 현 상태에 있다 — where research stands 연구의 현주소)so far지금까지 (≒ until now)ape유인원(침팬지·고릴라 등 꼬리 없음 / monkey '원숭이'와 혼동 주의)all (that) S knowS가 아는 전부 (관계대명사 that 생략)
📐 문장 구조도
✏️ 문법관계부사 where 보어절: this is exactly where modern research now stands = 이것이 바로 연구가 서 있는 지점이다 — where절이 be동사의 보어. / 관계대명사 생략 (all + 관계절): all (that) researchers know so far = 연구자들이 아는 전부 — 선행사 all 뒤 목적격 that 생략, 전체가 단수 주어. / 보어 that절 + 수 일치: all ~ is that apes possess ~ — 주어 all(전부·단수 취급) → is.
【현주소 — 확인된 건 '유인원' 하나뿐】 연구의 현주소 = 아직 초반. 지금껏 확실히 밝혀진 사실은 '유인원(침팬지 등)에게 거울 뉴런이 있다' 딱 하나뿐이라는 것. ★ 콜론(:) 뒤 = 앞 내용의 구체 설명.

🔊

📌species종(생물 분류 단위 — 단수·복수 형태 동일)be like~와 비슷하다, ~와 같다in this respect이 점에서 (respect 다의어: ① 존경 ② 점·측면)test검사하다, 실험하다 (→ testable 검증 가능한)
📐 문장 구조도
✏️ 문법need to V + 목적의 to부정사: need to test to see ~ = 알아보기 위해 검사할 필요가 있다 — to부정사 연쇄(test의 목적). / 간접의문문: see which other species are like us = 어떤 다른 종이 우리와 비슷한지 — see의 목적어. / in this respect: in this respect = 이 점(거울 뉴런 보유)에서 — respect '존경' 아님.
【과제 — 나머지 동물은 아직 미검사】 유인원 말고 다른 동물들도 이 부품(거울 뉴런)을 갖고 있는지는 아직 실험을 안 해 봤다는 것 — 확인해야 할 목록이 그대로 남아 있다. ★ still = '여전히' 남은 과제 신호.

Scientists often publicly speculate that we can probably expect surprises here, too.
🔊

📌publicly공공연히, 공개적으로 (→ public 공적인)speculate추측하다 (→ speculation 추측 / ≒ guess)probably아마 (≒ likely)expect기대하다, 예상하다 (→ expectation 기대)surprise놀라운 일, 뜻밖의 결과
📐 문장 구조도
✏️ 문법speculate that + 절: speculate that we can expect ~ = ~라고 추측하다 — 완전한 절을 이끄는 that. / 조동사 겹침 can probably: can probably expect = 아마 기대할 수 있다 — 조동사 + 부사. / here, too: here, too = 여기(다른 종 검사)에서도 — 앞선 발견들처럼.
【예측 — '뚜껑을 열면 놀랄걸?'】 과학자들의 감: 검사해 보면 유인원 말고도 거울 뉴런을 가진 동물이 꽤 나올 거라는 것 — 놀랄 준비를 하라는 공개적 예측이다. ★ surprises = 예상 밖의 '추가 발견'.
05
They assume that all animals that live in herds or large groups possess similar brain mechanisms, because social units function only if individuals can see things from the perspective of others in the group and feel what they are feeling.
🔊
그들(= 과학자들)은 무리나 큰 집단을 이루어 사는 모든 동물이 유사한 뇌 메커니즘을 지니고 있다고 가정하는데, 왜냐하면 사회적 단위는 개체들이 집단 내 다른 개체들의 관점에서 사물을 보고 그들(= 집단 내 다른 개체들)이 느끼는 것을 느낄 수 있어야만 제대로 기능하기 때문이다.
📌assume가정하다, 추정하다 (→ assumption 가정)herd(소·양 등의) 무리, 떼 (≒ flock 새 떼 / school 물고기 떼)brain mechanism뇌 메커니즘, 뇌의 작동 방식social unit사회적 단위(무리·집단)function기능하다, 제대로 돌아가다 (다의어: n. 기능)only if~해야만, ~인 경우에만perspective관점, 시각 (≒ viewpoint)feel what S+V~가 느끼는 것을 느끼다 (관계대명사 what)
📐 문장 구조도
✏️ 문법이중 that — 접속사 + 관계사(수 일치): assume that all animals that live in ~ possess ~ — 앞 that은 명사절 접속사, 뒤 that은 관계대명사(선행사 animals 복수 → live · 주어 all animals → possess). / only if 조건: function only if individuals can ~ = ~할 수 있어야만 기능한다 — 필수 조건. / 관계대명사 what: feel what they are feeling = 그들이 느끼는 것을 느끼다 — feeling의 목적어가 빠진 불완전한 절 → what.
【근거 — 무리 생활 = 공감 없이는 불가능】 이유: 무리 생활은 '남의 눈으로 보고 남의 기분을 느끼는' 능력 없이는 굴러가지 않는다. 그래서 소 떼든 새 떼든 물고기 떼든, 떼로 사는 동물이라면 비슷한 뇌 장치가 있을 거라는 가정. ★ only if = 사회적 단위의 필수 조건.

📐 문장 구조도

【장면 — '저도요!' 하는 금붕어】 글쓴이의 상상 장면: 금붕어가 '저도 껴 주세요!' 하듯 우리에게 지느러미를 흔드는 그림. 떼 지어 다니는 물고기도 그 후보라는 유머러스한 연결 고리다. ★ can see = 실제가 아닌 상상 속 장면.

As an animal that travels around in a tightly-knit group, it's on board with this idea—or at least swimming alongside the boat.
🔊
긴밀히 결속된 무리를 지어 돌아다니는 동물로서, 그것(= 금붕어)은 이 생각(= 무리 동물은 유사한 뇌 메커니즘을 지닌다는 가정)에 동참하고 있다 — 혹은 적어도 그 배 옆에서 나란히 헤엄치고 있다.
📌travel around돌아다니다, 이동해 다니다tightly-knit긴밀히 결속된 (≒ close-knit / ↔ loose 느슨한)be on board with~에 동참하다, 찬성하다 (배에 '올라탄' 데서 온 비유)at least적어도, 최소한alongside~와 나란히, ~ 옆에서 (≒ beside)
📐 문장 구조도
✏️ 문법자격의 As + 명사: As an animal that ~ = ~하는 동물로서 — 자격·신분의 as. / 관계사 that + 수 일치: an animal that travels around — 선행사 an animal(단수) → travels. / or 병렬 (is on board / is swimming): it's on board with ~ or at least swimming ~ — be동사에 걸리는 보어 병렬: 완전히 탑승했거나, 적어도 옆에서 헤엄치거나.
【결론(말장난) — 탑승 못 해도 나란히 헤엄】 말장난: on board(배에 올라탐) = 이 가설에 '탑승'(찬성)했다는 뜻. 금붕어는 아직 증명이 안 됐으니 배에 완전히 타진 못했지만, 적어도 배 '옆에서 나란히 헤엄치는' 중 — 가설과 같은 방향으로 가고 있다는 유머. ★ 밑줄 함축 = '가설에 부합하는 유력 후보'라는 뜻.

간접의문문 (의문사 + S + V)
see which animals possess these cells — 의문사 뒤 평서 어순. ✗ which do animals possess → ✓ which animals possess
Tier 2
수사의문문 what would make more sense than ~
what would make more sense than to V? = ~보다 더 이치에 맞는 게 뭐가 있겠는가 — 강한 긍정.
Tier 3
make sense
make sense = 이치에 맞다 — '감각을 만들다' 직역 금지.
문장 02 · 관계부사 where / all (that) 관계사 생략
And this is exactly where modern research now stands: all researchers know so far is that apes possess mirror neurons.
이것이 연구의 현주소다 — 아는 전부는 유인원이 거울 뉴런을 지닌다는 것.
Tier 1
관계대명사 생략 + 수 일치
all (that) researchers know so far is ~ — all 뒤 목적격 that 생략, 주어 all(단수) → is. ✗ are → ✓ is
Tier 2
관계부사 where 보어절
this is exactly where ~ stands = 이것이 바로 ~가 서 있는 지점이다.
Tier 3
stand (현 상태에 있다)
where modern research now stands = 연구의 현주소 — '서다' 직역 아님.
문장 03 · need to V / 간접의문문
We still need to test to see which other species are like us in this respect.
이 점에서 어떤 다른 종이 우리와 비슷한지 알아보기 위해 검사가 필요하다.
Tier 2
목적의 to부정사 연쇄
need to test to see ~ = 알아보기 위해 검사할 필요가 있다 — 뒤 to see는 목적.
Tier 2
간접의문문
see which other species are like us — 의문사 + S + V 평서 어순.
Tier 3
in this respect
in this respect = 이 점에서 — respect '존경' 아님(다의어).
문장 04 · speculate that / can probably
Scientists often publicly speculate that we can probably expect surprises here, too.
과학자들은 여기서도 놀라운 결과를 기대할 수 있다고 공공연히 추측한다.
Tier 1
speculate that + 완전한 절
speculate that we can expect ~ — 명사절 접속사 that. ✗ what → ✓ that
Tier 3
조동사 + 부사
can probably expect = 아마 기대할 수 있다.
Tier 4
here, too
here, too = 여기(추가 검사)에서도 — 첨가.
문장 05 · 이중 that / only if / 관계대명사 what
They assume that all animals that live in herds or large groups possess similar brain mechanisms, because social units function only if individuals can see things from the perspective of others in the group and feel what they are feeling.
무리 지어 사는 동물은 유사한 뇌 메커니즘을 지닌다고 가정한다 — 사회적 단위는 공감이 있어야만 기능하므로.
Tier 1
관계사 that + 수 일치
all animals that live in herds ~ possess ~ — 선행사 animals(복수) → live, 주어 all animals → possess. ✗ lives / possesses → ✓ live / possess
Tier 1
관계대명사 what
feel what they are feeling — feeling의 목적어가 빠진 불완전한 절 → what. ✗ that → ✓ what
Tier 2
only if 조건
function only if individuals can ~ = ~할 수 있어야만 기능한다 — 필수 조건.
문장 06 · 지각동사 see + O + V-ing
I can see a goldfish waving its fin at us.
금붕어가 우리에게 지느러미를 흔드는 모습이 그려진다.
Tier 1
지각동사 + 목적어 + 현재분사
see a goldfish waving its fin — 진행 중 동작 → 현재분사. ✗ to wave → ✓ waving
Tier 3
I can see (상상)
I can see ~ = ~하는 모습이 그려진다 — 상상의 장면.
Tier 4
방향의 at
waving its fin at us = 우리를 향해.
문장 07 · 자격의 As / 관계사 수 일치 / or 병렬
As an animal that travels around in a tightly-knit group, it's on board with this idea—or at least swimming alongside the boat.
긴밀한 무리로 다니는 동물로서, 금붕어는 이 생각에 동참 중 — 적어도 배 옆에서 헤엄치고 있다.
Tier 1
관계사 that + 수 일치
an animal that travels around — 선행사 an animal(단수) → travels. ✗ travel → ✓ travels
Tier 2
자격의 As + 명사
As an animal that ~ = ~하는 동물로서.
Tier 2
or 병렬 (be의 보어)
it's on board with ~ or at least swimming ~ — is에 걸리는 보어 병렬(on board / swimming).
