01
It’s important for humans to have many kinds of minds, because variation is critical for the survival of a species.
🔊
인간이 여러 종류의 마음을 갖는 것은 중요한데, 왜냐하면 변이(다양성)는 종의 생존에 매우 중요하기 때문이다.
📌many kinds of여러 종류의mind마음, 사고방식variation변이, 다양성 (vary → variation / various)critical for~에 매우 중요한 (≒ crucial, essential)survival생존 (survive → survival / survivor)species(생물의) 종 (단·복수 동형)
📐 문장 구조도
✏️ 문법가주어 It ~ 의미상 주어 for + 진주어 to V: It’s important for humans to have ~ — It은 가주어, for humans는 to have의 의미상 주어, to have ~가 진주어. / 이유 접속사 because: , because variation is critical ~ = 변이가 ~에 중요하기 때문에. / critical for + 명사: critical for the survival of a species = 종의 생존에 매우 중요한.
【주제문 — 마음이 여러 종류여야 종이 살아남음】 사람의 마음(생각하는 방식, 성격, 재능)이 여러 종류인 것이 왜 중요할까? 필자는 '변이(variation)', 즉 서로 다름이 종이 살아남는 데 결정적이기 때문이라고 답한다. 반 아이들이 전부 똑같은 성격이면 위기 때 아무도 다른 해법을 못 내놓듯, 생물도 마찬가지라는 주제문이다. ★ It's important for A to V — for A = 의미상 주어!
02
One of Charles Darwin’s greatest insights was that variation is a prerequisite for natural selection to work.
🔊
Charles Darwin의 가장 위대한 통찰 중 하나는 변이가 자연 선택이 작동하기 위한 전제 조건이라는 것이었다.
📌one of + 복수 명사~ 중 하나 (단수 취급)insight통찰(력) (in + sight)prerequisite전제 조건, 필수 조건natural selection자연 선택work (동사)작동하다, 효과가 있다 (≒ function)greatest가장 위대한 (great → greater → greatest)
📐 문장 구조도
✏️ 문법One of + 복수 명사 + 단수 동사: One of ~ insights was — 주어는 One(단수) → was. / was that + 절 (보어): was that variation is ~ = ~라는 것이었다 — that절이 보어. / for + 의미상 주어 + to V: a prerequisite for natural selection to work = 자연 선택이 작동하기 위한 전제 조건 — for natural selection이 to work의 의미상 주어.
【근거 ① — Darwin: 변이가 없으면 자연 선택도 없음】 다윈의 핵심 통찰 중 하나가 바로 이것이다. 자연 선택(환경에 맞는 개체가 살아남는 것)이 작동하려면 먼저 개체들이 서로 달라야(변이) 한다. 모두 똑같으면 '더 잘 맞는 개체'라는 것 자체가 있을 수 없으므로 선택할 것도 없다. 변이는 자연 선택의 '전제 조건(prerequisite)'이라는 뜻이다. ★ One of + 복수 명사 → 단수 동사 was!

03
Think about it: If there’s a huge change in the environment, like a catastrophic drop in the food supply or a big increase in temperature, a species without much variation might be completely wiped out.
🔊
이것(= 변이가 자연 선택의 전제 조건이라는 점)에 대해 생각해 보라: 식량 공급의 재앙적인 감소나 기온의 큰 상승과 같은 환경의 거대한 변화가 있다면, 변이가 많지 않은 종은 완전히 전멸할지도 모른다.
📌huge거대한 (≒ enormous)environment환경 (→ environmental)catastrophic재앙적인, 파멸적인 (catastrophe → catastrophic)drop in~의 감소 (↔ increase in ~의 증가)food supply식량 공급temperature기온, 온도be wiped out전멸하다, 완전히 사라지다completely완전히 (complete → completely)
📐 문장 구조도
✏️ 문법조건절 If there’s ~: If there’s a huge change ~, a species ~ might be — 조건절 + 주절(가능성 might). / 전치사 like (예시): like a catastrophic drop ~ or a big increase ~ = ~와 같은 — 예시 2개 병렬. / 수동태 be wiped out: might be completely wiped out = 완전히 전멸당할지도 모른다 — 조동사 + be + p.p. / 전치사구 후치수식 without: a species without much variation = 변이가 많지 않은 종.
【예시 ① — 변이 없는 종은 한 방에 전멸】 구체적으로 상상해 보라고 한다. 먹이가 갑자기 사라지거나 기온이 크게 오르는 큰 환경 변화가 왔을 때, 모든 개체가 똑같은 종은 한 번에 전멸할 수 있다. 예를 들어 한 품종만 심은 감자밭에 그 품종을 죽이는 병이 돌면 밭 전체가 망한다. 19세기 아일랜드 감자 대기근이 실제로 그랬다. ★ be wiped out = 전멸하다 ('닦아내다' ✗)!
04
A species with great variation will more likely have some survivors after any catastrophe―the members who are well suited for the new environment.
🔊
변이가 큰 종은 어떤 재앙 뒤에도 생존자들을 가질 가능성이 더 높을 것이다 ― 새로운 환경에 잘 적합한 구성원들 말이다.
📌more likely더 ~할 가능성이 높은 (↔ less likely)survivor생존자 (survive → survival / survivor)catastrophe재앙, 대참사 (≒ disaster)member구성원be well suited for~에 잘 맞는, 적합한 (≒ be suitable for)suit → suitable맞다 → 적합한
📐 문장 구조도
✏️ 문법동격 명사구 ―the members: some survivors ― the members who ~ — 대시 뒤 명사구가 survivors를 구체적으로 다시 설명(동격). / 주격 관계대명사 who: the members who are well suited for ~ — 선행사 members(복수) → are. / 부사구 more likely: will more likely have = ~를 가질 가능성이 더 높다. / 전치사구 후치수식 with: A species with great variation = 변이가 큰 종 (↔ S3 without).
【예시 ② — 변이 큰 종은 누군가는 살아남음】 반대로 개체들이 다양한 종은 재앙이 와도 누군가는 살아남는다. 추위에 강한 개체, 다른 먹이를 먹을 수 있는 개체처럼 '새 환경에 잘 맞는(well suited)' 구성원이 있기 때문이다. 여러 품종을 섞어 심은 밭은 병이 돌아도 일부는 살아남는 것과 같다. ★ ― the members who ~ = survivors의 동격!

05
Darwin observed variation in the bodies of animals, and the same principle applies to human minds.
🔊
Darwin은 동물의 몸에서 변이를 관찰했는데, 같은 원리(= 변이가 종의 생존을 돕는다는 원리)가 인간의 마음에도 적용된다.
📌observe관찰하다 (→ observation)body / bodies몸 (복수 -ies)principle원리, 원칙 (↔ principal 주요한; 교장)apply to~에 적용되다 (cf. apply for ~에 지원하다)the same같은, 동일한
📐 문장 구조도
✏️ 문법apply to (자동사 + 전치사): the same principle applies to human minds = 같은 원리가 인간의 마음에 적용된다 — 주어 principle(단수) → applies. / 등위접속사 and (전환): Darwin observed ~, and the same principle ~ — 동물의 몸 → 인간의 마음으로 논의 확장. / principle ↔ principal: principle(원리) — 철자 혼동 주의.
【전환 — 동물의 '몸'에서 인간의 '마음'으로】 다윈은 동물의 '몸'에서 변이를 관찰했다. 핀치새 부리 모양이 섬마다 다른 것이 유명한 예다. 필자는 같은 원리가 인간의 '마음'에도 적용된다고 말한다. 몸의 다양성이 종을 지키듯, 생각하는 방식의 다양성이 인류를 지킨다는 전환점이다. ★ apply to = ~에 적용되다 / apply for = ~에 지원하다!
06
If we all had the same kind of mind―if there were only one human nature―then when disaster struck, we might become extinct.
🔊
만약 우리 모두가 같은 종류의 마음을 가지고 있다면 ― 만약 오직 하나의 인간 본성만 있다면 ― 그러면 재난이 닥쳤을 때 우리는 멸종할지도 모른다.
📌human nature인간 본성disaster재난, 재해 (≒ catastrophe)strike / struck / struck(재난이) 닥치다, 덮치다extinct멸종한 (→ extinction 멸종)become extinct멸종하다 (≒ die out)the same kind of같은 종류의
📐 문장 구조도
✏️ 문법가정법 과거 If + 과거동사, S + might + V: If we all had ~, we might become extinct — 현재 사실의 반대(실제로는 마음이 다양함)를 가정. / 가정법 과거 if there were: if there were only one human nature — 가정법에서 be동사는 were. / 대시로 삽입된 재진술: ―if there were only one human nature― — 앞 조건절을 바꿔 말한 삽입구. / when disaster struck (가정법 시제 일치): when disaster struck = 재난이 닥쳤을 때 — 가정법 과거에 맞춘 과거형.
【반대 가정 — 마음이 다 똑같다면 인류는 멸종】 만약 모든 인간의 마음이 똑같다면, 즉 '인간 본성'이 단 한 가지뿐이라면 어떻게 될까? 큰 재난이 닥쳤을 때 모두가 같은 방식으로 반응하고 같은 실수를 해서 멸종할 수도 있다. 모두가 겁쟁이거나 모두가 무모하면, 도망쳐야 할 때와 맞서야 할 때 중 하나를 전부 놓친다. ★ If + 과거(had/were), might + V = 가정법 과거!
07
Thankfully, our species has many kinds of minds, both within a single culture and across cultures, so we’re less likely to be wiped out.
🔊
다행히도, 우리 종은 하나의 문화 안에서도, 그리고 여러 문화에 걸쳐서도 여러 종류의 마음을 갖고 있어서, 우리는 전멸할 가능성이 더 낮다.
📌thankfully다행히도 (≒ fortunately)within~ 안에서single단 하나의across~에 걸쳐, ~ 전역에be less likely to VV할 가능성이 더 낮다 (↔ more likely)culture문화 (→ cultural)
📐 문장 구조도
✏️ 문법both A and B (전치사구 병렬): both within a single culture and across cultures — 전치사구 2개 병렬. / 결과 접속사 so: ~, so we’re less likely to ~ = 그래서 ~할 가능성이 더 낮다. / be less likely to V: less likely to be wiped out = 전멸당할 가능성이 더 낮은 — to 뒤 수동(be + p.p.). / our species has (단수): our species has — species는 단·복수 동형, 여기서는 단수 → has.
【현실 — 다행히 인류의 마음은 다양해서 안전】 다행히 인류의 마음은 다양하다. 한 문화 안에서도 신중한 사람과 대담한 사람, 분석적인 사람과 직관적인 사람이 있고, 문화끼리도 다르다. 그래서 어떤 위기가 와도 누군가는 살아남을 방법을 찾는다. 인류가 '전멸당할(wiped out)' 가능성이 낮은 이유다. ★ less likely to V ↔ more likely to V!
08
This variation preserves the evolvability of our species.
🔊
이러한 변이(= 인간 마음의 다양성)가 우리 종의 진화 가능성을 보존한다.
📌preserve보존하다, 지키다 (→ preservation)evolvability진화 가능성 (evolve → evolution → evolvability)evolve진화하다variation변이, 다양성
📐 문장 구조도
✏️ 문법지시형용사 This + 명사: This variation = (앞서 말한) 이러한 변이 — 인간 마음의 다양성을 받음. / 3인칭 단수 현재 preserves: This variation preserves — 주어 단수 → -s.
【결론 — 마음의 다양성이 인류가 계속 진화할 힘을 지킴】 결론. 마음의 다양성은 인류가 '계속 진화할 수 있는 능력(evolvability)'을 지켜 준다. 지금 당장 살아남는 것뿐 아니라, 앞으로 어떤 환경이 오든 그에 맞게 변해 갈 힘을 유지한다는 뜻이다. 다양한 마음이 인류의 보험이자 미래 대비책이라는 것이 글의 요지다. ★ evolvability = evolve + -ability (진화할 수 있는 능력)!

Darwin의 원리: 변이(variation)가 있어야 재앙 뒤에도 살아남는 개체가 있다. 이 원리는 인간의 마음에도 적용된다.
여러 종류의 마음(마음의 다양성)이 인류의 생존과 진화 가능성을 지킨다
🔑 핵심 대조 — 변이 없는 종 vs 변이 큰 종
✗ 변이 없음 (without variation)
식량 급감·기온 급상승 같은 환경 변화 → 완전히 전멸(wiped out) · 마음이 하나뿐인 인류 → 재난 시 멸종(extinct)
vs
○ 변이 큼 (great variation)
재앙 뒤에도 새 환경에 잘 맞는 생존자 존재 · 문화 안·문화 간 여러 종류의 마음 → 전멸 가능성 ↓ · 진화 가능성 보존
💡 주제: 인간 마음의 다양성(변이)이 종의 생존과 진화 가능성에 갖는 중요성.

ⓐ — 주제 제시와 Darwin의 통찰 (S1~S2)
인간이 여러 종류의 마음을 갖는 것이 중요하다 — 변이는 종의 생존에 결정적이다. Darwin의 통찰: 변이는 자연 선택이 작동하기 위한 전제 조건.
▷ 문법: 가주어 It ~ for A to V · because · One of + 복수 명사 + 단수 동사 · for + 의미상 주어 + to V
ⓑ
ⓑ — 예시: 변이와 재앙 (S3~S4)
식량 급감·기온 급상승 같은 거대한 환경 변화가 오면, 변이가 적은 종은 전멸할 수 있다. 변이가 큰 종은 새 환경에 잘 맞는 구성원, 즉 생존자를 가질 가능성이 더 높다.
▷ 문법: 조건절 If · 전치사 like · 수동태 be wiped out · 동격 ― the members who ~

ⓒ — 인간 마음에 적용과 결론 (S5~S8)
같은 원리가 인간의 마음에도 적용된다. 마음이 하나뿐이라면 재난 시 멸종할 수 있지만, 다행히 인류는 문화 안·문화 간에 여러 종류의 마음을 가져 전멸 가능성이 낮다. 이 변이가 인류의 진화 가능성을 보존한다.
▷ 문법: apply to · 가정법 과거(had / were / might) · both A and B · less likely to V · This + 명사

문장 01 · 가주어 It / for + 의미상 주어 + to V / because
It’s important for humans to have many kinds of minds, because variation is critical for the survival of a species.
인간이 여러 종류의 마음을 갖는 것은 중요한데, 변이는 종의 생존에 매우 중요하기 때문이다.
Tier 1
가주어 It ~ 진주어 to V + 의미상 주어 for
It’s important for humans to have — 사람의 성질 형용사가 아니므로 for(of 아님). ✗ of humans to have → ✓ for humans to have
Tier 2
이유 접속사 because + 절
because variation is critical — because 뒤 완전한 절. ✗ because of variation is → ✓ because variation is
Tier 3
critical for / species
critical for = ~에 매우 중요한 / species = 종(단·복수 동형).
문장 02 · One of + 복수 + 단수 동사 / was that / for A to V
One of Charles Darwin’s greatest insights was that variation is a prerequisite for natural selection to work.
Charles Darwin의 가장 위대한 통찰 중 하나는 변이가 자연 선택이 작동하기 위한 전제 조건이라는 것이었다.
Tier 1
One of + 복수 명사 + 단수 동사
One of ~ insights was — 주어는 One. ✗ were → ✓ was
Tier 1
보어 that절
was that variation is ~ — 완전한 절 → 접속사 that. ✗ was what variation is → ✓ was that variation is
Tier 2
for + 의미상 주어 + to V
a prerequisite for natural selection to work = 자연 선택이 작동하기 위한 전제 조건.
Tier 3
insight / prerequisite
insight = 통찰 / prerequisite = 전제 조건.
문장 03 · 조건절 If / 전치사 like / 수동태 be wiped out
Think about it: If there’s a huge change in the environment, like a catastrophic drop in the food supply or a big increase in temperature, a species without much variation might be completely wiped out.
이것에 대해 생각해 보라: 식량 공급의 재앙적인 감소나 기온의 큰 상승과 같은 환경의 거대한 변화가 있다면, 변이가 많지 않은 종은 완전히 전멸할지도 모른다.
Tier 1
조동사 + 수동태 might be wiped out
might be completely wiped out — 종은 전멸'당하는' 대상 → 수동. ✗ might completely wipe out → ✓ might be completely wiped out
Tier 2
조건절 If there’s ~, 주절
If there’s a huge change ~, a species ~ might be ~ — 조건 + 결과.
Tier 2
전치사 like (예시 병렬)
like a catastrophic drop ~ or a big increase ~ = ~와 같은(≒ such as).
Tier 3
drop in ↔ increase in
a drop in the food supply(감소) ↔ an increase in temperature(증가).
문장 04 · 동격 ― / 관계사 who / more likely
A species with great variation will more likely have some survivors after any catastrophe―the members who are well suited for the new environment.
변이가 큰 종은 어떤 재앙 뒤에도 생존자들을 가질 가능성이 더 높을 것이다 ― 새로운 환경에 잘 적합한 구성원들 말이다.
Tier 1
주격 관계대명사 who + 수 일치
the members who are well suited — 선행사 members(복수) → are. ✗ who is → ✓ who are
Tier 1
동격 명사구 ―the members
some survivors―the members who ~ — 대시 뒤 명사구 = survivors의 동격.
Tier 2
부사구 more likely
will more likely have = ~을 가질 가능성이 더 높다.
Tier 3
be well suited for
well suited for the new environment = 새 환경에 잘 맞는.
문장 05 · apply to / and 전환
Darwin observed variation in the bodies of animals, and the same principle applies to human minds.
Darwin은 동물의 몸에서 변이를 관찰했는데, 같은 원리가 인간의 마음에도 적용된다.
Tier 1
apply to + 수 일치
the same principle applies to — 주어 principle(단수) → applies. ✗ apply to → ✓ applies to
Tier 2
apply to vs apply for
apply to = ~에 적용되다 / apply for = ~에 지원하다.
Tier 3
principle ↔ principal
principle(원리) — principal(주요한; 교장)과 철자 혼동 주의.
문장 06 · 가정법 과거 / when disaster struck
If we all had the same kind of mind―if there were only one human nature―then when disaster struck, we might become extinct.
만약 우리 모두가 같은 종류의 마음을 가지고 있다면 ― 오직 하나의 인간 본성만 있다면 ― 재난이 닥쳤을 때 우리는 멸종할지도 모른다.
Tier 1
가정법 과거 If + 과거, S + might + V
If we all had ~, we might become extinct — 현재 사실의 반대. ✗ If we all have ~, we might → ✓ If we all had ~, we might
Tier 1
가정법 be동사 were
if there were only one human nature — 가정법 과거의 be는 were. ✗ if there was → ✓ if there were
Tier 2
삽입 재진술 ―if ~―
―if there were only one human nature― — 앞 조건절을 바꿔 말한 삽입구.
Tier 3
become extinct / strike
become extinct = 멸종하다 / struck = strike(닥치다)의 과거.
문장 07 · both A and B / so / less likely to V
Thankfully, our species has many kinds of minds, both within a single culture and across cultures, so we’re less likely to be wiped out.
다행히도, 우리 종은 하나의 문화 안에서도, 여러 문화에 걸쳐서도 여러 종류의 마음을 갖고 있어서, 우리는 전멸할 가능성이 더 낮다.
Tier 1
be less likely to + 수동
less likely to be wiped out — to 뒤 수동태. ✗ to wipe out → ✓ to be wiped out
Tier 1
species 단수 취급 has
our species has — species는 단·복수 동형, 여기선 단수. ✗ our species have → ✓ our species has
Tier 2
both A and B (전치사구)
both within a single culture and across cultures — 전치사구 병렬.
Tier 3
결과 접속사 so
, so we’re less likely ~ = 그래서 ~.
문장 08 · This + 명사 / 3인칭 단수 동사
This variation preserves the evolvability of our species.
이러한 변이가 우리 종의 진화 가능성을 보존한다.
Tier 2
3인칭 단수 현재 -s
This variation preserves — 주어 단수. ✗ preserve → ✓ preserves
Tier 3
evolvability
evolvability = 진화 가능성 (evolve + -ability).
Tier 4
지시형용사 This
This variation = 앞서 말한 인간 마음의 다양성.
