Subjective measures contain useful knowledge, but this can be difficult to share, based as it is on an individual’s experience.

03
The historian of science Theodore M. Porter describes measurement as a ‘technology of distance’: a tool that uses shared rules to bridge differences of culture and geography, allowing for the exchange of information.
🔊
과학사학자 Theodore M. Porter는 측정을 '거리의 기술'이라고 설명한다: 즉, 공유된 규칙을 사용해 문화와 지리의 차이를 메우고, 정보의 교환을 가능하게 하는 도구라는 것이다.
📌historian of science과학사학자describe A as BA를 B라고 설명하다technology기술distance거리shared rules공유된 규칙bridge (동사)(차이를) 메우다, 잇다geography지리 (→ geographical)allow for~을 가능하게 하다exchange교환
📐 문장 구조도
✏️ 문법describe A as B: describes measurement as a ‘technology of distance’ = 측정을 '거리의 기술'로 설명하다. / 콜론(:) 뒤 동격 명사구: : a tool that uses ~ — '거리의 기술'을 풀어 설명. / 주격 관계대명사 that + to V(목적): a tool that uses shared rules to bridge ~ = 차이를 메우기 위해 공유 규칙을 쓰는 도구. / 분사구문 , allowing for ~: , allowing for the exchange of information = 정보 교환을 가능하게 하면서(결과).
【정의 — 측정은 '거리의 기술': 공유 규칙으로 문화·지리 차이를 메움】 과학사학자 Porter는 측정을 '거리의 기술'이라고 정의한다. 멀리 떨어진 사람끼리도 같은 규칙(단위)으로 재면 서로 이해할 수 있다는 뜻이다. 한국의 공장과 독일의 설계자가 '2.5cm'라는 공유 규칙으로 부품을 맞추는 것이 그 예다. 문화도 언어도 다른 사람 사이의 '거리'를 단위가 메워 준다. ★ describe A as B / bridge = (차이를) 메우다!

04
Following this logic, if measurement is another sort of language, then just as with words, individual units need reliable definitions in order to communicate.
🔊
이 논리(= 측정은 거리의 기술이라는 논리)를 따르면, 측정이 또 다른 종류의 언어라면, 단어와 마찬가지로 개별 단위도 소통하기 위해서는 신뢰할 수 있는 정의가 필요하다.
📌following (전치사)~을 따라, ~에 따르면logic논리another sort of또 다른 종류의just as with~와 마찬가지로individual (형용사)개별의reliable신뢰할 수 있는 (rely → reliable)definition정의 (define → definition)in order to VV하기 위해
📐 문장 구조도
✏️ 문법분사구문 Following this logic: Following this logic = 이 논리를 따르면. / 조건절 if ~, then ~: if measurement is ~, then ~ units need ~. / in order to V (목적): in order to communicate = 소통하기 위해. / just as with + 명사: just as with words = 단어의 경우와 꼭 마찬가지로.
【적용 — 측정이 언어라면 단위에도 믿을 만한 '뜻'이 필요】 측정이 일종의 언어라면, 단어에 사전적 뜻이 있어야 대화가 되듯 단위에도 모두가 믿을 수 있는 '정의'가 있어야 소통이 된다. '사과'라는 단어의 뜻이 사람마다 다르면 대화가 안 되듯, '1미터'가 정확히 얼마인지 정해져 있지 않으면 측정으로 소통할 수 없다는 비유다. ★ just as with words = 단어와 마찬가지로!
05
In the earliest societies, these definitions might need to be shared no more widely than a single settlement, meaning that the definition can be no more complex than knowing that a unit was equal to a certain body part.
🔊
가장 초기의 사회에서는, 이러한 정의(= 단위의 정의)가 하나의 정착지보다 더 넓게 공유될 필요는 없었을 것이고, 이는 그 정의가 어떤 단위가 특정 신체 부위와 같다는 것을 아는 것보다 더 복잡할 필요가 없다는 뜻이다.
📌the earliest가장 초기의 (early → earlier → earliest)society사회need to be p.p.~될 필요가 있다no more ~ than~보다 더 ~하지 않은settlement정착지, 마을complex복잡한be equal to~과 같다body part신체 부위
📐 문장 구조도
✏️ 문법need to be + p.p. (수동): need to be shared = 공유될 필요가 있다. / no more ~ than (비교급 부정): no more widely than a single settlement = 하나의 정착지보다 더 넓게는 아닌 / no more complex than knowing ~ = ~을 아는 것보다 더 복잡하지 않은. / 분사구문 , meaning that ~: , meaning that the definition can be ~ = 이는 ~라는 뜻이다. / knowing that + 절: knowing that a unit was equal to ~ = 단위가 ~과 같다는 것을 아는 것.
【초기 사회 — 마을 안에서만 통하면 되니 '손 한 뼘' 정도로 충분】 아주 옛날 작은 마을에서는 단위의 정의를 마을 밖까지 공유할 필요가 없었다. 마을 사람끼리만 통하면 되니 '1단위 = 어른 발 길이'처럼 몸을 기준으로 정해도 충분했다. 실제로 피트(feet)는 발 길이, 큐빗은 팔꿈치에서 손끝 길이에서 나온 단위다. 작은 공동체에서는 이 정도로 족했다는 것이다. ★ no more ~ than = ~보다 더 ~하지 않은!

【전환 — 공동체가 커지자 몸 기준 단위의 한계가 드러남】 '하지만(though)' 마을이 커지고 다른 마을과 거래하기 시작하면 문제가 드러난다. '누구 발 길이가 기준이냐?'는 질문이 생기고, 발이 큰 사람과 작은 사람이 재면 곡식 양이 달라진다. 몸 기준 단위의 '부적절함'이 분명해지는 순간이다. 문장 삽입 문제에서는 이 반전(though)이 결정적 단서다. ★ though(삽입) = 하지만 — 문장 삽입의 단서!
07
Imagine a disagreement over trade or tribute: it is a moment of conflict that demands greater consistency in measurement.
🔊
무역이나 공물을 둘러싼 의견 불일치를 상상해 보라: 그것(= 무역이나 공물을 둘러싼 의견 불일치)은 측정에서 더 큰 일관성을 요구하는 갈등의 순간이다.
📌imagine상상하다disagreement over~을 둘러싼 의견 불일치 (↔ agreement)trade무역, 거래tribute공물, 조공conflict갈등demand요구하다greater consistency더 큰 일관성
📐 문장 구조도
✏️ 문법명령문 Imagine + O: Imagine a disagreement over ~ = ~을 둘러싼 의견 불일치를 상상해 보라. / 콜론(:) 뒤 설명: : it is a moment of conflict ~ — 앞 상황을 풀이. / 주격 관계대명사 that + 단수 동사: a moment of conflict that demands — 선행사 a moment(단수) → demands.
【결론 — 거래·공물 다툼이 일관된 측정을 요구함】 결론을 장면으로 보여 준다. 옆 마을과 곡식을 거래하거나 영주에게 공물을 바칠 때 '네가 잰 게 적다'며 다툼이 벌어지는 순간을 상상해 보라. 그런 갈등이 생기면 누구 발이 아니라 모두가 인정하는 통일된 단위가 필요해진다. 갈등이 일관된 측정을 요구한다는 것이 글의 결론이다. ★ tribute = 공물 ('찬사' ✗)!

🌱 CORE MESSAGE — 전체 글의 메시지
측정 단위가 제 힘을 발휘하려면 일관성이 필요하다. 측정은 공유 규칙으로 거리를 넘는 '거리의 기술'이며, 언어처럼 단위에도 믿을 만한 정의가 필요하다.

문장 01 · To V 목적 / some degree of
To harness the full potential of units of measurement, we need some degree of consistency.
측정 단위의 잠재력을 온전히 활용하려면, 우리는 어느 정도의 일관성이 필요하다.
Tier 2
to부정사 부사적 용법(목적)
To harness ~, we need ~ = ~을 활용하기 위해.
Tier 2
some degree of + 명사
some degree of consistency = 어느 정도의 일관성.
Tier 3
harness / potential
harness = 활용하다 / full potential = 최대 잠재력.
문장 02 · difficult to V / based as it is on
Subjective measures contain useful knowledge, but this can be difficult to share, based as it is on an individual’s experience.
주관적 측정법은 유용한 지식을 담고 있지만, 이것은 공유하기 어려울 수 있는데, 그것이 개인의 경험에 근거한 것이기 때문이다.
Tier 1
난이 형용사 + to V (목적어 없음)
this can be difficult to share — 주어 this가 share의 의미상 목적어 → 뒤에 it 불가. ✗ difficult to share it → ✓ difficult to share
Tier 1
분사구문 + as it is (이유 강조)
based as it is on ~ = 그것이 ~에 근거한 것이므로 — 과거분사 based. ✗ basing as it is on → ✓ based as it is on
Tier 3
subjective / contain
subjective = 주관적인 / contain = 담고 있다.
문장 03 · describe A as B / that uses ~ to bridge / allowing for
The historian of science Theodore M. Porter describes measurement as a ‘technology of distance’: a tool that uses shared rules to bridge differences of culture and geography, allowing for the exchange of information.
과학사학자 Theodore M. Porter는 측정을 '거리의 기술', 즉 공유된 규칙으로 문화와 지리의 차이를 메워 정보 교환을 가능하게 하는 도구라고 설명한다.
Tier 1
주격 관계대명사 that + 단수 동사
a tool that uses shared rules — 선행사 a tool(단수) → uses. ✗ that use → ✓ that uses
Tier 1
분사구문 , allowing for
, allowing for the exchange of information — a tool이 가능하게 하는 주체 → 현재분사. ✗ allowed for → ✓ allowing for
Tier 2
describe A as B
describes measurement as a ‘technology of distance’.
Tier 2
to V 목적
uses shared rules to bridge differences = 차이를 메우기 위해 공유 규칙을 쓰다.
Tier 3
bridge / geography / allow for
bridge = (차이를) 메우다 / geography = 지리 / allow for = 가능하게 하다.
문장 04 · Following / if ~ then / just as with / in order to V
Following this logic, if measurement is another sort of language, then just as with words, individual units need reliable definitions in order to communicate.
이 논리를 따르면, 측정이 또 다른 종류의 언어라면, 단어와 마찬가지로 개별 단위도 소통하기 위해서는 신뢰할 수 있는 정의가 필요하다.
Tier 2
분사구문 Following this logic
Following this logic = 이 논리를 따르면.
Tier 2
if ~, then ~
if measurement is ~, then ~ units need ~ — 조건과 결과.
Tier 2
in order to V
in order to communicate = 소통하기 위해. ✗ in order communicating → ✓ in order to communicate
Tier 3
just as with / reliable
just as with words = 단어와 마찬가지로 / reliable = 신뢰할 수 있는.
문장 05 · need to be p.p. / no more ~ than / meaning that
In the earliest societies, these definitions might need to be shared no more widely than a single settlement, meaning that the definition can be no more complex than knowing that a unit was equal to a certain body part.
가장 초기의 사회에서는 이러한 정의가 하나의 정착지보다 더 넓게 공유될 필요는 없었을 것이고, 이는 그 정의가 단위가 특정 신체 부위와 같다는 것을 아는 것보다 더 복잡할 필요가 없다는 뜻이다.
Tier 1
need to be + p.p.
need to be shared — 정의는 공유'되는' 대상. ✗ need to share → ✓ need to be shared
Tier 1
분사구문 , meaning that
, meaning that the definition can be ~ = 이는 ~라는 뜻이다. ✗ , meant that → ✓ , meaning that
Tier 2
no more ~ than
no more widely than / no more complex than = ~보다 더 ~하지 않은.
Tier 3
settlement / be equal to
settlement = 정착지 / be equal to = ~과 같다.
문장 06 · As절 / 삽입 though / would become
As these communities grew in size, though, the inadequacies of this system would become evident.
하지만 이러한 공동체의 규모가 커지면서, 이 체계의 부적절함이 분명해졌을 것이다.
Tier 2
접속사 As (~함에 따라)
As these communities grew in size = 규모가 커짐에 따라.
Tier 2
삽입 부사 though
~, though, ~ = 하지만 — 앞 문장과의 반전.
Tier 2
would + become + 형용사
would become evident = 분명해졌을 것이다.
Tier 3
inadequacy / evident
inadequacy = 부적절함 / evident = 분명한.
문장 07 · 명령문 Imagine / that demands
Imagine a disagreement over trade or tribute: it is a moment of conflict that demands greater consistency in measurement.
무역이나 공물을 둘러싼 의견 불일치를 상상해 보라: 그것은 측정에서 더 큰 일관성을 요구하는 갈등의 순간이다.
Tier 1
주격 관계대명사 that + 단수 동사
a moment of conflict that demands — 선행사 a moment(단수). ✗ that demand → ✓ that demands
Tier 2
명령문 Imagine + O
Imagine a disagreement over trade or tribute = ~을 둘러싼 불일치를 상상해 보라.
Tier 3
tribute / demand
tribute = 공물 / demand = 요구하다.
