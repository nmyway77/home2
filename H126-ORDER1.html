1단계. 주어진 글: "무엇을 꺼냈고, 어떻게 끝났나"

주어진 글을 읽으면서 두 가지만 여백에 적어요. 해석을 통째로 하지 말고, 이 두 가지가 나오면 바로 다음 단계로 넘어가세요.

1-1. 꺼낸 명사 목록

주어진 글에 등장한 대상(사람·사물·개념)을 적어 두세요. 이 목록에 없는 것을 "그것(this, it, they, the ~)"처럼 이미 아는 듯이 가리키는 단락은 첫 자리에 올 수 없어요.

주어진 글: "일부 동물은 언어 없이도 생각할 수 있다고 가정하자." → 목록: 동물, 생각. 다람쥐(squirrel)·나뭇가지·개념(concept)은 없음. 그래서 "squirrels lack concepts"로 시작하는 단락은 첫 자리 불가. → 실전 3번

1-2. 마지막 문장의 유형 → 다음 내용 예측

마지막 문장이…다음에 올 가능성이 큰 것실전
질문으로 끝남그 질문에 답하는 문장. 답으로 시작하는 단락이 첫 단락.8번

2단계. 세 단락의 첫 문장에서 단서 찾기

이 단계에서는 각 단락의 첫 문장만 봐요. 첫 문장의 맨 앞 한두 단어와 명사 앞의 관사·지시어에 동그라미를 치면 돼요. 아래 여덟 개 블록이 그 동그라미를 칠 대상이에요. 각 블록은 "원리 → 어디를 보나 → 무엇을 결정하나 → 실전 예" 순서예요. 처음엔 A·B·C 세 가지만 익혀도 대부분 풀리고, D~H는 A·B·C로 안 갈릴 때 쓰는 보조 단서예요.

A

지시어·대명사

This / It / They / These / Those / Such a ~ / One of these / the same

원리 "그거"라고 하려면 앞에 "그거"가 있어야 해요. 문장 맨 앞의 지시어가 가리키는 대상이 주어진 글(또는 앞 단락)에 이미 나와 있어야 그 자리에 올 수 있어요.
어디를 보나
  • 각 단락 첫 문장의 첫 단어: This, It, They, These, Those, Such
  • 첫 문장 안의 this/these/those + 명사: this concrete form of thinking, These kids, Those empires
  • 갑자기 나오는 she / he / it
  • 지시어의 단수·복수: This(하나) vs These/They(여럿)
무엇을 결정하나
  • 가리킬 대상이 주어진 글에 없으면 → 첫 자리 불가
  • 대상이 특정 단락에서 처음 나오면 → 그 단락 바로 뒤
  • These/They인데 앞에 단수만 있으면 → 그 뒤에 못 옴
  • 동사를 명사로 바꿔 받는 This + 명사(squeezes → This squeezing)는 → 그 동사가 나온 단락 바로 뒤가 확정
실전 예
(B) …much of the fluid squeezes out→(A) This squeezing of joint fluid…(B)→(A) 확정
(A) …we were confused→(C) Our confusion was about…(A)→(C) 확정
주어진 글: 동물이 생각할 수 있다고 가정→(C) This doesn't mean they possess conceptsThis=가정, they=동물 → 첫 자리 OK
주어진 글: 아이들 없음→(A) These kids end up…가리킬 아이들 없음 → 첫 자리 불가

→ 실전 3·4·6·10번

주의 It이 "가주어"(It is important that ~)나 날씨·시간의 it이면 앞의 대상이 필요 없어요. It 뒤에 동사가 바로 오고 "그것"으로 번역이 되는지 확인하세요.
B

관사와 재지칭

a / an(처음) → the / 대명사 / 복수형(다시)

원리 처음 소개할 때는 a squirrel(어떤 다람쥐), 그다음부터는 the squirrel / she / squirrels(그 다람쥐). 같은 명사가 두 단락에 나오면 a가 붙은 쪽이 먼저예요. 해석을 안 해도 순서가 잡혀요.
어디를 보나
  • 같은 명사가 두 단락 이상에 나오는지 먼저 찾기(squirrel, force, bladder)
  • 그 명사 앞의 a / the / its / 복수형 확인
  • 고유명사·직책도 마찬가지: "Dr. Carol Dweck" → 뒤는 "Dweck"
  • "a ~ who / that …"처럼 관계절로 길게 설명하는 문장은 소개하는 문장
무엇을 결정하나
  • a + 명사가 있는 단락 → 그 명사가 나오는 다른 단락들보다 앞
  • the / its / 대명사 / 복수형으로만 부르는 단락 → 뒤
  • 주어진 글에 없는 명사를 the/its로 부르면 → 첫 자리 불가
  • 단락 끝이 a + 명사로 끝나고 다음 단락이 the + 같은 명사로 시작하면 → 그 두 단락은 붙어 있음
실전 예
(C) …a squirrel who is planning…→(B) …she doesn't need…→(A) …squirrels lack concepts
(B) …they must be exerting a force→(C) This is the force called friction(B)→(C) 확정
주어진 글: "your knee"만 있음→(B) The cartilage in your left knee then…"왼쪽" 무릎을 이미 아는 듯 → 첫 자리 불가

→ 실전 3·4·8번

주의 the가 있다고 무조건 "재지칭"은 아니에요. the sun, the world처럼 원래 the를 쓰는 명사, "the + 최상급"은 제외. 같은 명사가 다른 단락에 a로도 나올 때만 이 규칙을 쓰세요.
C

연결사

However / In contrast / For example / Therefore / Then / Rather / If so / In this sense / Also

원리 연결사는 "내 앞에는 이런 내용이 있어야 한다"는 조건표예요. 단락 첫 문장의 연결사를 보고, 주어진 글(또는 앞 단락 끝)이 그 조건을 채우는지 확인하면 자리가 정해져요.
어디를 보나
연결사앞에 있어야 하는 것
However / But / Yet반대 내용
In contrast / On the other hand / Unlike비교할 반대쪽 사례 전체
For example / For instance일반적 주장
Therefore / So / Thus / As a result원인·근거
Then / Next / After that먼저 일어난 일
Rather / Instead"~가 아니다" 부정문
If so / If not질문 또는 조건
In this sense / In other words같은 내용(재진술)
Also / too / Even / And it does not stop there이미 나열된 것
무엇을 결정하나
  • 주어진 글이 조건을 못 채우면 → 첫 자리 불가. 특히 In contrast·The same applies·Then·Rather·If so는 주어진 글로는 거의 못 채워요.
  • However/But은 주어진 글에 "당연하게 여긴다·흔히 그렇다"류의 통념이 있으면 첫 자리 가능
  • For instance는 주어진 글이 주장으로 끝났을 때 첫 자리 1순위
  • So/Therefore + 글 전체 평가("~는 지나친 단순화다")는 마지막 단락
  • 남은 두 단락 비교 때는 첫 단락 끝 문장이 조건을 채우는지로 둘째를 정함
실전 예
주어진 글: 감각 경험을 당연하게 여긴다→(B) However, closer inspection reveals…통념→반전, 첫 자리 OK
주어진 글: growth mindset 소개(반대쪽 없음)→(B) In contrast, kids praised for effort…비교 대상 없음 → 첫 자리 불가
(B) …But is this always the case?→(A) If so, archaeology would be boring질문→If so, (B)→(A) 확정
(C) …So … "history repeats itself" is an oversimplification.So + 전체 평가 → 마지막

→ 실전 5·6·7·9번

주의 연결사가 문장 중간에 있을 때(kids who are praised, for instance, …)도 같은 조건이 적용돼요. 그리고 연결사 하나만 보고 끝내지 말고, 그 연결사가 요구하는 내용이 정확히 앞에 있는지 내용으로 한 번 확인하세요.
D

순번·열거 표현

The same applies / Similarly / Likewise / Another / One of these / Some ~ others / partly ~ partly

원리 이 표현들은 문장 스스로 "나는 두 번째다" 또는 "앞에 여러 개가 있다"고 밝히고 있어요. 그래서 첫 자리에 올 수 없고, 짝이 되는 문장 뒤에만 올 수 있어요.
어디를 보나
  • "~도 마찬가지"류: The same applies to ~, Similarly, Likewise, In the same way
  • "또 하나"류: Another ~, a second ~, the other ~
  • "여럿 중 하나"류: One of these ~, One of them, Some ~ / Others ~
  • 짝으로 다니는 표현: partly ~ / partly ~, on the one hand ~ / on the other hand ~, not only ~ / but also ~
무엇을 결정하나
  • The same applies / Similarly로 시작 → 첫 사례가 있는 단락 뒤. 첫 사례는 보통 for instance가 있는 단락.
  • One of these / Another로 시작 → 바로 앞 단락 끝에 복수 명사가 있어야 함. 단수(a force)만 있으면 불가.
  • 짝 표현은 한쪽이 나온 단락 바로 뒤에 나머지 한쪽이 옴.
  • 같은 단락 안에 for example이 있어도, 문장 맨 앞이 The same applies면 두 번째 사례로 취급.
실전 예
(B) For many children, for instance, 'Right'…→(A) The same applies to 'Yes' and 'No'…첫 사례→두 번째 사례
(C) …there are other friction forces→(A) One of these is friction… Another is air resistance복수→하나씩 세기, (C)→(A) 확정
(B) …a force(단수)✗(A) One of these…단수 뒤에 "이것들 중"은 불가

→ 실전 8·10번

E

소개하는 말투 vs 이미 아는 말투

something else — / Imagine / Consider / which X calls "~" vs so important / its extended ~ / These ~

원리 같은 명사가 두 단락에 있는데 관사로도 구분이 안 될 때는, 그 명사를 처음 소개하듯 말하는지, 이미 아는 것처럼 말하는지 말투로 판단해요. 소개하는 쪽이 앞이에요.
어디를 보나
소개하는 말투(앞)이미 아는 말투(뒤)
relies on something else — its bladder
(뜸 들이고 대시(—) 뒤에 공개)		because its bladder is so important
(중요하다는 걸 전제)
Imagine ~ / Consider ~ / Let's say ~
(장면·예시를 새로 염)		its extended hibernation
(동면을 이미 아는 듯 수식)
~, which Dweck calls a "fixed mindset"
(용어에 이름을 붙임)		These kids / Those empires
(어느 것인지 안다는 전제)
There is / There are ~ (존재를 알림)~ is still / also / again ~
무엇을 결정하나
  • 두 단락 모두 같은 명사를 쓰면 → 소개 말투 단락이 앞, 전제 말투 단락이 뒤
  • Imagine / Consider로 시작하는 단락은 주어진 글이 짧은 결론만 던졌을 때 첫 자리 1순위
  • "so + 형용사", "such a ~"처럼 정도를 강조하는 말은 그 정도를 앞에서 설명했다는 뜻 → 뒤
실전 예
(A) the reptile relies on something else — its highly sophisticated bladder→(C) And because its bladder is so important…(A)→(C)
주어진 글: 연골이 중요하다→(C) Imagine for a moment that you're looking into your left knee…장면 열기, 첫 자리
(C) …which Dweck calls having a "fixed mindset."→(B) In contrast, … "growth mindset."용어 도입 후 대조

→ 실전 4·6·7번

F

질문 → 답

What happens? / But is this always the case? / Why? / How could you ~?

원리 질문으로 끝난 문장 바로 다음은 그 질문에 답하는 문장이에요. 주어진 글이 질문으로 끝나면 첫 단락은 답으로 시작하는 단락이고, 어떤 단락이 질문으로 끝나면 그 다음 단락은 답(또는 If so)으로 시작해요.
어디를 보나
  • 주어진 글의 마지막 문장에 물음표가 있는지
  • 각 단락의 마지막 문장에 물음표가 있는지(다음 단락을 결정하는 단서)
  • 세 단락 첫 문장 중 짧고 단정적인 답처럼 보이는 것: "You gradually slow down."
  • If so / If not / Yes / No / The answer is ~로 시작하는 문장
무엇을 결정하나
  • 주어진 글이 질문 → 답으로 시작하는 단락이 첫째
  • 단락 X가 질문으로 끝남 → X 바로 뒤는 답 또는 "If so"
  • 질문에 답하지 않고 딴 얘기로 시작하는 단락은 질문 바로 뒤에 못 옴
실전 예
주어진 글: …no force is acting. What happens?→(B) You gradually slow down.(B)가 첫째
(B) …But is this always the case?→(A) If so, archaeology would be pretty boring; … But that's not what archaeologists see.(B)→(A)

→ 실전 5·8번

G

어휘 사슬(꼬리–머리 연결)

앞 단락의 마지막 문장 ↔ 다음 단락의 첫 문장

원리 붙어 있는 두 단락은 앞 단락의 마지막 문장에 나온 단어가 다음 단락의 첫 문장에 다시 나와요. 그대로 반복되기도 하고, 형태를 바꿔(동사→명사, 단수→정관사, 복수→하나씩) 나오기도 해요. 4단계(남은 두 단락 순서 정하기)에서 가장 강력한 단서예요.
어디를 보나
  • 첫 단락 마지막 문장의 핵심 명사·동사에 밑줄
  • 남은 두 단락의 첫 문장에서 그 단어(또는 변형)를 찾기
  • 변형 유형: 동사→명사(squeezes→squeezing, confused→confusion), a→the(a force→the force), 복수→One of these, 동의어·상위어(planning→To do this)
무엇을 결정하나
  • 꼬리 단어를 받는 단락이 둘째, 못 받는 단락이 셋째
  • 둘 다 받는 것 같으면 → 더 구체적인 단어(branch, tree)를 받는 쪽이 둘째
  • 둘째 단락의 끝과 셋째 단락의 첫 문장도 같은 방법으로 한 번 더 확인
실전 예
(C) …planning how to get from the branch … to a branch from the tree→(B) To do this, she doesn't need a concept of branch nor of tree(C)→(B)
(B) …their effort is what led to their success→(A) These kids… "Emphasizing effort gives a child…"(B)→(A)
(C) …food textures, tastes, and smells(나열)→(A) And it does not stop there. Even the sounds…나열에 하나 더, (C)→(A)

→ 실전 3·4·6·8·9·10번

주의 단어가 겹친다고 무조건 붙이면 안 돼요. bladder처럼 두 단락에 다 있으면 단서 B·E(관사·말투)로 어느 쪽이 먼저인지 정하세요. 사슬은 "끝 문장 → 첫 문장" 사이에서만 세요. 단락 중간의 단어는 세지 마세요.
H

시제·비교급·긍정/부정의 방향

was / is · less / more ~ · 부정문 → Rather · 나열 → But

원리 문장의 형태만으로도 위치가 보일 때가 있어요. 시제가 갈리면 두 대상을 나눠 설명하는 중이고, 비교급은 비교 대상이 앞에 있어야 하며, 긍정↔부정이 바뀌는 지점엔 반드시 연결사가 있어요.
어디를 보나
  • 단락마다 주된 시제: 과거(was, had to)와 현재(is, can)가 갈리는지
  • less / more / -er than이 첫 문장에 있는지
  • 단락 끝이 부정문("~가 아니다")인지, 긍정 나열인지
  • still / also / no longer / even 같은 부사
무엇을 결정하나
  • 과거 설명이 모두 끝난 뒤 현재 설명이 옴(옛날 vs 지금, A vs B 구조)
  • less/more + 형용사 → 비교 대상이 있는 단락 뒤
  • 단락 끝이 부정문 → 다음은 Rather / Instead로 시작하는 단락
  • 단락 끝이 긍정 나열 → 다음은 But / However로 꺾거나, Also / Even으로 하나 더 얹는 단락

3단계. 첫 자리에 올 수 없는 단락 지우기

2단계에서 찾은 단서를 주어진 글의 "꺼낸 명사 목록"과 대조해서, 아래에 하나라도 걸리면 그 단락은 첫 자리 불가예요. 첫 단락이 정해지면 선택지는 자동으로 2개만 남으니, 이 단계가 문제의 절반이에요.

첫 자리 불가 판정 기준

  1. 첫 문장의 this / it / they / these / such / the + 명사가 가리킬 대상이 주어진 글에 없다.
  2. 주어진 글에 없는 명사를 이미 아는 듯이(the ~, its ~, 복수·대명사로) 부른다.
  3. In contrast / The same applies / Another / One of these처럼 "두 번째"임을 밝히는 표현으로 시작한다.
  4. But / However로 시작하는데 주어진 글에 반대 내용이 없다.
  5. Then / If so / Rather로 시작하는데 주어진 글이 그 조건(먼저 일어난 일·질문·부정문)을 채우지 않는다.
  6. So / Therefore + 글 전체 평가로 시작한다(이건 보통 마지막 단락).

보통 두 단락이 지워지고 하나만 남아요. 만약 두 단락이 다 첫 자리 가능해 보이면, 주어진 글의 "마지막 문장 유형"(1-2)과 더 정확히 맞물리는 쪽을 고르세요. 예를 들어 주어진 글이 주장으로 끝났으면 for instance가 있는 단락이, 질문으로 끝났으면 답으로 시작하는 단락이 첫째예요.

흔한 실수: 주어진 글이 growth mindset을 소개했으니 "growth mindset을 설명하는 (B)가 다음이겠지" — 하지만 (B)의 첫 단어가 In contrast. 내용이 친숙하다고 고르지 말고 첫 어구가 앞에 뭘 요구하는지로 판단하세요. → 6번

4단계. 남은 두 단락의 순서: 꼬리와 머리를 맞춰 보기

첫 단락이 정해지면 선택지는 2개. 이제 첫 단락의 마지막 문장과 남은 두 단락의 첫 문장을 나란히 놓고 어느 쪽이 붙는지 봐요. 확인 순서는 이래요.

  1. 어휘 사슬(단서 G): 첫 단락 끝의 단어를 그대로·변형해서 받는 쪽이 둘째.
  2. 단수·복수 / a·the: 첫 단락 끝이 단수(a force)면 "the force"가 둘째, "One of these"는 셋째.
  3. 연결사 조건표(단서 C): 둘째 후보의 연결사가 첫 단락 끝과 맞는가. 질문 → If so, 부정 → Rather, 나열 → And it does not stop there.
  4. 소개 말투 vs 기지 말투(단서 E): 같은 명사를 두 단락이 다 쓰면 소개하는 쪽이 둘째.
  5. 마지막 단락 판별: 아래 특징이 있는 단락은 셋째로 보내요.

마지막 단락의 특징

  • So / Therefore / Thus로 시작하거나 그 문장으로 끝남 — 글 전체 평가("~는 지나친 단순화다"). 5번
  • 구체적 예를 일반화함("For us to say an animal has concepts, we have to show…"). 3번
  • 앞에서 설명한 과정의 효과·의미를 정리함("This squeezing … helps it respond…"). 4번
  • 인용문·격언으로 마무리(" ~," Dweck has explained.). 6번
  • 목록에 마지막 항목을 추가함(And it does not stop there. Even the sounds…). 9번

5단계. 정한 순서로 읽으며 검증하기

정한 순서로 주어진 글부터 끝까지 한 번 쭉 읽어요. 이때 확인할 것은 세 가지.

  • 각 단락의 첫 문장 대명사·연결사가 바로 앞 단락 끝과 맞물리는가.
  • 이야기 흐름이 한 방향인가: 도입 → 구체화/예시 → 결론. 중간에 결론이 나왔다가 다시 예시로 돌아가면 틀린 순서예요.
  • 오답 선택지를 한 번 대입해서 어디서 말이 끊기는지 찾아 보세요. 끊기는 지점을 설명할 수 있으면 확신이 생겨요.

실전 체크리스트

  • 주어진 글에서 꺼낸 명사를 적었다. 마지막 문장 유형(질문/주장/도입)을 확인했다.
  • (A)(B)(C) 첫 문장의 지시어·관사·연결사·순번 표현에 표시했다.
  • 첫 자리 불가 기준 1~6에 걸리는 단락을 지웠다. 선택지가 2개로 줄었다.
  • 첫 단락 끝과 남은 두 단락 첫 문장을 나란히 놓고 어휘 사슬·단수복수·연결사로 둘째를 정했다.
  • 셋째 단락이 결론(So / 일반화 / 효과 정리)처럼 끝나는지 봤다.
  • 정한 순서로 한 번 통독했고, 오답 선택지가 어디서 끊기는지 말할 수 있다.

노란 형광펜 = "앞에 뭔가 있어야 말이 되는" 단어. 이 단어가 문장 맨 앞에 있으면 그 문장은 첫 번째가 될 수 없어요.

파란 형광펜 = 글에서 처음 등장하는 새로운 것. 뒤에서 "그것(it, this, they)"으로 다시 불리게 될 대상이에요.
